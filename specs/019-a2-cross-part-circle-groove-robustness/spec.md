# Feature Specification: A2 跨零件圆与真槽鲁棒性

**Feature Branch**: `019-a2-cross-part-circle-groove-robustness`

**Created**: 2026-08-16

**Status**: Draft

**Input**: User description: "基于009确认的物理零件分组，对part-008、009、014、015、019、021、023的圆定位、物理圆、暗区候选和真槽唯一性失败开展根因修复；不读取或重跑已消耗的part-006，不用无真值数据宣称准确率，按物理零件隔离开发与验证。"

## Clarifications

### Session 2026-08-16

- Q: 现有A2数据是否可以用作严格未见精度测试？ → A: 不可以；700张均已暴露，只能用于分组开发、验证和非严格过渡证据。
- Q: 是否可以为了让失败组通过而直接放宽圆残差、槽宽波动或候选唯一性门限？ → A: 不可以；未有独立人工真值时必须保持安全失败。
- Q: 已消耗的normal:part-006如何处理？ → A: 封存，不读取逐图结果、不重跑、不调参。
- Q: 85°附近没有完整20帧组是否阻塞当前鲁棒性开发？ → A: 不阻塞；499–500仅作停止区间功能烟测，不作静态重复性。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 看清失败发生在哪一层 (Priority: P1)

作为算法和现场负责人，我需要每张图的圆候选、稀疏物理圆、最终物理圆、环形暗区、真槽门控和唯一性有独立状态与可解释证据，从而区分“没找到壳体”、“圆被局部污染”、“没生成暗区”和“两个暗区都像槽”。

**Why this priority**: 现有顶层错误码不足以支撑安全调整；观测性是后续任何鲁棒性改动的前置条件。

**Independent Test**: 使用受控圆污染、负暗阈值、0/1/2个通过槽候选和环绕边界样例，不依赖现场图即可校验每层状态、门限余量和失败原因。

**Acceptance Scenarios**:

1. **Given** 唯一壳体粗候选且某些圆周扇区残差异常，**When** 完成物理圆评估，**Then** 结果分别记录全局残差、分扇区残差、异常扇区覆盖和拒绝原因。
2. **Given** 环形亮度统计会导出不可用的暗阈值，**When** 生成候选，**Then** 结果记录原始阈值、有界候选阈值、每个假设的来源和拒绝原因，不以raw=0掩盖原因。
3. **Given** 0个或多于1个真槽候选，**When** 计算姿态，**Then** 仍返回结构化失败且不输出角度或引导量。

---

### User Story 2 - 在有上限的实验模式中提升鲁棒性 (Priority: P1)

作为算法负责人，我需要用传统几何方法处理局部遮挡、刻字、反光和宽亮度分布，但这些改动在独立人工真值完成前必须保持可配置、有硬上限且默认不改变现行生产路径。

**Why this priority**: part-019已证明单一中位数/MAD阈值可以落到灰度取值范围之外；part-008/009/023已证明圆拟合对局部污染敏感。

**Independent Test**: 在已知圆心/半径和已知真槽的合成图上注入有上限的连续污染扇区、阴影、弱槽、多暗区和宽亮度分布，验证实验模式能恢复唯一可信结果，超出限制时安全失败。

**Acceptance Scenarios**:

1. **Given** 真圆上存在少量连续异常扇区且剩余角覆盖充足，**When** 启用实验圆鲁棒模式，**Then** 系统只能排除有证据的有上限扇区，并对保留点重新通过完整物理圆质量门。
2. **Given** 异常扇区过多、剩余角覆盖不足或多个圆解无法唯一，**When** 评估圆，**Then** 返回不可引导，不以排除大量数据换取通过。
3. **Given** 原始暗阈值越界，**When** 启用有界多假设候选，**Then** 每个阈值必须在有效灰度范围内，假设数不超过配置上限，且仅唯一真槽通过时可输出姿态。
4. **Given** 实验模式未启用，**When** 运行旧配置和历史合成用例，**Then** 原有legacy、paired、multi-role和single-real-groove路径的结果与契约保持兼容。

---

### User Story 3 - 按物理零件验证而不泄漏 (Priority: P2)

作为质量负责人，我需要将开发、验证和未来测试按完整物理零件隔离，不得把同一零件的20帧拆到两侧，也不得读取已消耗的part-006。

**Why this priority**: 当前700张已经暴露，只能通过物理零件级别的交叉验证降低针对单组过拟合的风险，不能恢复严格盲测身份。

**Independent Test**: 使用无图像的合成分组清单验证整零件分折、封存组拒绝、源图哈希隔离、折叠可复算和每折结果独立汇总。

**Acceptance Scenarios**:

1. **Given** 一个sample包含一个或多个condition，**When** 生成开发/验证折，**Then** 该sample的所有图像只能出现在同一侧。
2. **Given** 输入包含normal:part-006或其任一源图哈希，**When** 生成开发或验证任务，**Then** 工具在执行检测前拒绝并记录封存泄漏。
3. **Given** 失败类型只有一个物理零件，**When** 生成评估计划，**Then** 工具将其标为“不足以估计泛化”，不通过拆帧伪造多个样本。
4. **Given** 所有折都已暴露，**When** 生成报告，**Then** 报告标明为分组开发/验证，禁止标记为严格test或accuracy。

---

### User Story 4 - 用最少人工标注解锁生产决策 (Priority: P3)

作为现场审查人，我需要一份不根据算法成败挑选角度真值的小型标注队列，对圆有效弧、唯一真槽、两个阴影暗区和槽口两端/侧壁进行复核。

**Why this priority**: 圆残差门、槽宽波动门和多候选取舍都可能将错误几何变成“有效”，必须用非运行时人工真值解锁。

**Independent Test**: 对受控的外置标注清单执行完整性和溯源验证，确保每个根因家族至少覆盖一个完整物理零件的代表帧，且标注不会进入生产运行时。

**Acceptance Scenarios**:

1. **Given** 候选标注队列，**When** 审查队列生成，**Then** 每个样本记录选择规则、sample/condition、失败阶段、源图哈希和所需shape，不预填算法候选为真值。
2. **Given** 人工真值未完成，**When** 生成默认配置，**Then** 实验鲁棒模式保持关闭，并将生产激活状态标为BLOCKED。
3. **Given** 真值已完成，**When** 评估候选改动，**Then** 报告分别给出圆几何误差、真槽识别结果、角度环形差值、失败原因和静态稳定性，不用算法输出作真值。

### Edge Cases

- 圆异常扇区跨越0°/360°边界时，必须合并为同一连续扇区。
- 圆上真槽本身导致局部凹入时，排除策略不得用85°目标方向选择要保留的圆。
- 异常扇区遮蔽过多或剩余点分布在单侧时，必须失败，不得外推完整圆。
- 有界暗阈值在纯黑、纯白、低对比或强反光环形上产生0或大量候选时，必须给出明确不可用/溢出状态。
- 多个暗阈值假设产生同一物理候选时，必须按环形角中心和宽度聚类去重，不能把阈值重复当成多槽歧义。
- 封存sample更名、路径变化或图像改变时，以源图SHA-256识别泄漏，不仅比较sampleId。
- 同一根因家族只有一个物理零件时，报告必须说明不足以估计泛化。
- 旧配置缺少新实验字段时，必须解析为关闭状态并保持旧结果契约。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 系统 MUST 将壳体粗候选、稀疏物理圆、最终物理圆、环形暗区、真槽识别和姿态输出建模为可独立追踪的阶段。
- **FR-002**: 每个圆阶段 MUST 输出点数、内点率、角覆盖、全局P95径向残差、门限余量和失败项。
- **FR-003**: 最终物理圆评估 MUST 提供版本化的分扇区残差证据，包含每区点数、中位/P95/最大残差、异常标记和环绕边界。
- **FR-004**: 任何鲁棒圆重拟合 MUST 限制可排除扇区数、最大连续排除角和最小保留角覆盖，超限必须失败。
- **FR-005**: 鲁棒圆重拟合 MUST 在保留点上重新执行完整几何质量门，不得仅因排除异常点就判定成功。
- **FR-006**: 鲁棒圆选择 MUST 与槽目标85°、调整方向和PLC状态解耦。
- **FR-007**: 环形暗区生成 MUST 保留原始统计阈值，并在其非有限或越出有效灰度范围时输出明确原因。
- **FR-008**: 实验暗区模式 MUST 只生成有界、有上限、可溯源的多阈值假设，并对跨假设的同一环形候选去重。
- **FR-009**: 每个阈值假设 MUST 输出生成的原始暗区、被过滤暗区及其过滤原因，不得只输出最终数量。
- **FR-010**: 真槽识别 MUST 只消费去重后的原始暗区，角中心、宽度、径向深度、对比、边缘对和轮廓证据不得丢失。
- **FR-011**: single-real-groove模式在真槽数量为0或大于1时 MUST 安全失败，`currentAngleDeg`、`correctionDeg`和正式引导量必须为`null`。
- **FR-012**: 实验鲁棒模式 MUST 默认关闭；旧配置不提供新字段时 MUST 与当前生产行为兼容。
- **FR-013**: 实验配置 MUST 版本化并严格验证数值范围、候选上限、扇区上限和相互约束；错误配置必须在检测前拒绝。
- **FR-014**: 现有v1/v2/v3结果消费者 MUST 继续可用；新诊断字段优先作为向后兼容扩展，只有无法表达状态时才允许升版。
- **FR-015**: 开发/验证分折 MUST 使用009确认的sampleId和conditionId，不得使用算法角度、错误码或有效率反推物理分组。
- **FR-016**: 一个物理sample的所有condition、重复帧和源图lineage MUST 位于同一个evaluation purpose。
- **FR-017**: 分折工具 MUST 在运行检测前拒绝normal:part-006或封存源图哈希的任何出现。
- **FR-018**: 对只有一个物理零件的失败家族，系统 MUST 报告样本不足，不得拆分帧来生成交叉验证折。
- **FR-019**: 每折报告 MUST 分开报告圆候选、稀疏圆、最终圆、暗区、真槽、槽壁精修和顶层质量门漏斗，且保留每个错误码。
- **FR-020**: 评估报告 MUST 将检测有效性、当前姿态、图像坐标引导量、PLC执行可用性和人工真值准确率分开，不得相互替代。
- **FR-021**: 标注队列 MUST 使用与算法结果无关的完整物理零件选择规则，并保存源图相对路径、SHA-256、分组权威和所需shape。
- **FR-022**: 人工真值只能进入评估工具，MUST NOT 进入生产运行时或候选选择。
- **FR-023**: 所有外置图像、标注、回放结果和联系表 MUST 留在Git外；仓库只保存脱敏统计、契约、配置模板和小型合成夹具。
- **FR-024**: 本功能 MUST NOT 修改PLC、上位机、85°目标、±5°容差、图像y-down坐标或正顺时针契约。
- **FR-025**: 性能报告 MUST 区分默认基线与实验模式，报告单图P50/P95/max、批量吞吐、候选/重拟合次数上限和峰值内存。
- **FR-026**: 非严格过渡组的已消耗claim MUST 保持不可重跑；本功能的任何工具不得绕过009的一次性锁。

### Key Entities

- **Circle Stage Evidence**: 一次粗候选、稀疏拟合或最终拟合的几何、质量、门限余量和失败状态。
- **Angular Sector Evidence**: 圆周上版本化的连续角区间，包含点数、残差摘要、异常与排除原因。
- **Dark Threshold Hypothesis**: 一个有界暗阈值及其来源统计、偏移、原始候选和拒绝摘要。
- **Deduplicated Dark Candidate**: 跨阈值假设聚类后的唯一环形暗区，保留所有来源假设和环绕边界。
- **Robustness Profile**: 默认关闭的版本化实验配置，定义候选、扇区、排除和运算上限。
- **Part Fold**: 按完整sample组成的开发或验证分折，包含源图哈希集合和泄漏审计。
- **Annotation Queue Item**: 不预填算法真值的人工审查单元，记录物理零件、根因家族和所需几何shape。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 受控测试中100%的圆失败都能定位到粗候选、稀疏拟合、最终拟合或顶层质量门之一，且带门限余量。
- **SC-002**: 已知圆的合成污染测试在允许污染范围内恢复的圆心误差不大于0.5 px、半径误差不大于0.5 px；超过范围时100%安全失败。
- **SC-003**: 宽亮度分布导致原始暗阈值越界的合成测试中，100%输出有界阈值假设或明确不可用状态，不再无解释地输出raw=0。
- **SC-004**: 所有0槽、多槽、阴影歧义、过量圆污染和错误配置用例都不输出非空引导角。
- **SC-005**: 默认关闭实验模式时，现有legacy、paired、multi-role、single-real-groove、契约和CLI测试100%通过，历史合成基线无回退。
- **SC-006**: 分折审计100%拒绝同sample跨purpose、同lineage跨purpose和part-006泄漏，并在检测前失败。
- **SC-007**: 指定7个根因组的历史结果审计可在5秒内完成，不读取原图、不读取part-006逐图结果。
- **SC-008**: 实验模式候选数、阈值假设数和圆重拟合次数均有配置硬上限；性能测试证明新增P95延迟不超过0.8秒，单进程峰值内存不超过1.5 GiB，并记录测试环境。
- **SC-009**: 仓库污染审计不发现A2原图、联系表、视频、压缩包、运行输出、现场绝对路径或超限大文件。
- **SC-010**: 在没有新人工真值时，所有报告100%使用“检测候选/分组验证”表述，不输出或宣称百分比精度。
- **SC-011**: 标注队列覆盖稀疏圆边界、稀疏圆系统超限、最终圆超限、双槽歧义、暗区生成0个和真槽0个六类根因，每项记录所需人工shape和选择规则。

## Assumptions

- 009的confirmed grouping是当前物理sample/condition的权威来源；算法角度和像素差只作支持证据。
- 当前只有一张人工标注参考，不足以判定7个失败零件中的圆或真槽是否准确。
- normal:part-006的一次性过渡claim已消耗，其聚合结论可作历史证据，但逐图结果和原图不再读取。
- 85°目标、±5°容差、左下方目标、图像y轴向下、正值顺时针和最短调整量契约已由007确认，本功能不重定义。
- PLC相机/执行机映射仍未现场确认；图像坐标引导可用不代表PLC执行命令可用。
- 当前服务器仅有历史JSON/CSV/联系表和少量代表JPEG，没有这7个零件的完整原始BMP；真图实验模式回放需在Mac上执行。
- 开发期优先使用传统几何、环形剖面和现有圆拟合能力，不引入训练模型或新生产依赖。

## Out of Scope and Blocked Decisions

- **OUT-001**: 不修改PLC地址、缩放、字节序、上位机或机械执行逻辑。
- **OUT-002**: 不训练分割/分类模型，不使用生成式图像补全。
- **OUT-003**: 不删除A2图像，不把图像、视频、联系表或原始标注提交Git。
- **OUT-004**: 不将当前700张或封存过渡组宣称为严格未见测试。
- **BLOCKED-B01**: 鲁棒实验模式默认启用和生产门限变更，必须等待失败零件的独立圆/真槽人工真值与分组验证。
- **BLOCKED-B02**: 真槽歧义组中哪一个候选是物理真槽，必须由人工标注确认，不得依靠分数、目标角或算法有效率推断。
- **BLOCKED-B03**: 百分比绝对角精度仍只能使用新的原始BMP人工真值和独立物理零件评估；本功能不解除该阻塞。
