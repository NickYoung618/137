# Feature Specification: A2双缺口槽姿态稳定检测与真实数据验收

**Feature Branch**: `003-a2-paired-notch-stability`

**Created**: 2026-08-14

**Status**: Draft — 服务器可实现范围已明确，生产引导仍受现场决策阻塞

**Input**: 在已有`002-slot-pose-estimation` MVP上增量完成A2环形外缘多候选提取、
双缺口配对诊断、安全失败和Mac外置真实数据验收闭环；保留历史单notch结果作对照，
不重写A端面圆心、尺度、极坐标或配准链。

## Clarifications

### Session 2026-08-14

- Q: A2的生产目标是单个缺口、双缺口中某一个，还是两缺口夹持的中心线？ → A: 未确认，保持BLOCKED，两种模式仅供诊断。
- Q: A2正常集的500张是否固定按25组×20帧解析？ → A: 不是；必须依采集记录或时间序列确认条件组，不从文件数推断。
- Q: 旧`transform.rotation_deg`能否作为生产姿态？ → A: 不能；它仅作polar/legacy对照诊断，不得自动映射为机械角。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 获得可解释的外缘多候选和双缺口诊断 (Priority: P1)

算法工程师对单张A端面图像运行检测时，可查看环形外缘的所有暗区候选、候选质量、
排名差距，以及严格校验后的双缺口中心线诊断，用于解释旧字段在相似画面上跳变的原因。

**Why this priority**: 目标消歧和单图稳定性是A2批量验收前的核心技术缺口。

**Independent Test**: 在带独立双缺口真值的受控图像上，核对候选数量、每个候选的角中心/
半宽/显著度/环形边界、配对唯一性、中心线角和失败原因，不需要A2原图或PLC。

**Acceptance Scenarios**:

1. **Given** 外缘有两个质量足够且几何关系唯一的相邻缺口，**When** 运行
   `paired_notches_centerline`诊断，**Then** 返回全部候选、唯一配对和环形中心线角。
2. **Given** 缺少一侧缺口、存在多个等价配对或额外暗区使次优差距不足，**When** 运行paired诊断，
   **Then** 返回可区分失败且不带正式角。
3. **Given** 候选或配对跨越`0°/360°`边界，**When** 计算角间距、边界和中心线，**Then** 全部使用环形语义，
   不产生边界跳变。
4. **Given** 选择`legacy_single_notch`，**When** 运行历史合成扫角，**Then** 原有单notch候选、质量门控
   和角度精度不回退。

---

### User Story 2 - 不可靠时安全失败 (Priority: P1)

集成工程师在目标语义、机械坐标或检测质量未满足时，只能收到本任务的无效结果和明确原因，
而不是0度、旧姿态或过期候选。

**Why this priority**: 诊断模式尚未具有生产语义，任何误解为机械角都可能导致错误动作。

**Independent Test**: 分别输入配置错误、缺槽、多义配对、裁切端面、圆心/尺度异常、polar/notch
不一致及未确认机械语义样例，验证正式角和置信度均为空。

**Acceptance Scenarios**:

1. **Given** 目标槽语义、零位、正方向或有效范围任一未确认，**When** 检测形成诊断候选，
   **Then** `signedRelativeRotationDeg=null`、`valid=false`且错误说明阻塞门。
2. **Given** paired模式的候选数量、两侧槽宽/显著度、角间距、配对唯一性、环绕边界、
   圆心/尺度或polar/notch一致性任一未通过，**When** 生成结果，**Then** 失败且正式角为空。
3. **Given** 前一张图有效而当前图失败、任务过期或任务标识不匹配，**When** 下游读取结果，
   **Then** 当前结果不带任何可执行角度，不复用旧值。

---

### User Story 3 - 在Mac批量验收A2正常集和坏图集 (Priority: P2)

数据与质量工程师在Mac上对不进Git的A2外置数据生成可追溯Manifest，导入独立角度真值，
按采集条件组、物理样品和split隔离运行批处理，并生成正常集和坏图集的分开报告。

**Why this priority**: 服务器合成图只能验证工程链，生产可用性必须在可追溯的真实A2数据上评估。

**Independent Test**: 使用不含原图的小型Manifest、truth CSV、正常/坏图结果样例，验证分组、
泄漏防护、环形误差、失败统计和报告完整性。

**Acceptance Scenarios**:

1. **Given** A2外置目录和采集记录，**When** 生成Manifest，**Then** 使用相对路径记录文件指纹、
   条件组、物理样品、帧序号和split，且组合关系来自记录/时序而非固定文件数。
2. **Given** 不同真值角度的多个条件组，**When** 评估跨组稳定性，**Then** 对每帧环形相对真值误差/
   残差做统计，不对原始角度均值求动态极差。
3. **Given** 正常集批量结果，**When** 生成报告，**Then** 包含MAE/P95/max、有效率、同条件静态极差、
   跨组残差统计、失败原因和耗时。
4. **Given** 坏图集批量结果，**When** 生成报告，**Then** 包含误引导/false-positive数量与比率、
   失败原因和耗时，且所有失败角度均为空。
5. **Given** 同一物理样品或原图派生版跨split，或truth与Manifest指纹/分组不匹配，**When** 验证数据，
   **Then** 验收被阻止并报告具体冲突。

---

### User Story 4 - 为后续安全集成保持兼容边界 (Priority: P3)

上位机/PLC集成方可继续解析现有v2结果，新增候选和配对数据仅作向后兼容诊断；在接口字段、
地址、缩放、字节序、握手和失败动作未确认前，不进行真实控制写入。

**Why this priority**: 先稳定算法和验收契约，避免未确认的控制细节反向污染姿态语义。

**Independent Test**: 使用现有v2最小消费者样例验证旧必填字段、状态和失败不变，同时新诊断字段可被旧消费者忽略。

**Acceptance Scenarios**:

1. **Given** 现有v2消费者，**When** 解析带新诊断字段的结果，**Then** 旧必填字段的类型、语义和
   fail-closed不变，不需要为诊断增量强制升版。
2. **Given** PLC映射或机械语义尚未确认，**When** 运行任何服务器或Mac批处理，**Then** 不产生地址、
   缩放整数、字节序编码或控制写入。

### Edge Cases

- 一个缺口恰好跨越`359°/0°`，或两个配对候选分居环绕边界两侧。
- 两侧缺口宽度或显著度不对称，但仍在受控允许比率内；超限时必须失败。
- 第三个暗区产生另一个合法配对，最佳/次佳配对差距不足。
- 缺失一侧缺口、外缘被裁切或圆心偏差使环形采样不完整。
- 光照、噪声、油污、划痕、孔、文字或刀纹形成额外暗区。
- 缩放、平移或亮度变化超出受控范围，polar和notch路径不一致。
- 候选中心线在`+179°/-179°`两侧波动，评估仍应得到小的环形残差。
- Manifest有重复/缺帧、时间序列断裂、条件组未知或物理样品未知。
- 正常集缺真值、每组少于20帧或验收阈值未确认；报告必须标为不完整/未评定。
- 坏图被算法返回了任何`valid=true`结果；必须计为误引导，不能因角度接近零而忽略。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 系统 MUST 保留`legacy_single_notch`诊断模式作历史对照，不改变已有圆心、尺度、
  polar和单notch计算链的作用。
- **FR-002**: 系统 MUST 优先使用可解释的传统几何方案；未经冻结真实数据失败证据和单独评审，
  MUST NOT 引入学习模型。
- **FR-003**: 系统 MUST 从已有A端面圆心、尺度和polar链提供的环形外缘角度剖面中提取
  所有达到候选门槛的暗区，不得只保留最长暗区。
- **FR-004**: 每个外缘候选 MUST 记录稳定标识、环形角中心、半宽、显著度、起止边界、
  是否跨环绕边界及排名；摘要 MUST 包含候选数和最佳/次佳差距。
- **FR-005**: 系统 MUST 支持显式配置的`legacy_single_notch`和`paired_notches_centerline`诊断模式，
  MUST NOT 根据图像自动切换业务语义。
- **FR-006**: `paired_notches_centerline` MUST 对候选数量、两侧半宽及宽度比、两侧显著度及显著度比、
  环形角间距、配对最佳/次佳差距和配对唯一性逐项校验。
- **FR-007**: paired检测 MUST 对跨`0°/360°`的候选边界、角间距和中心线使用环形计算，
  不得用普通算术均值。
- **FR-008**: paired结果 MUST 同时通过圆心在图内、有效环形未被不可接受裁切、尺度范围、
  polar质量及polar旋转与notch/配对旋转一致性门控；任一失败即拒绝。
- **FR-009**: 系统 MUST 为无候选、候选不足、候选过多/配对不唯一、两侧质量不匹配、角间距越界、
  环形裁切、圆心/尺度失效、polar/notch不一致和配置错误输出可区分原因。
- **FR-010**: 任何检测失败、候选不唯一、图像质量不足、结果不一致、任务过期或外部语义未确认时，
  MUST 返回`valid=false`且正式角/置信度为空，MUST NOT 返回0度或复用旧角。
- **FR-011**: 目标槽语义未由机械方确认前，两种模式的所有角均只是诊断候选，不得自动成为生产机械角。
- **FR-012**: 机械零位、顺/逆时针正方向、有效范围或坐标映射未确认时，即使诊断通过，
  正式角 MUST 为空且结果 MUST 无效。
- **FR-013**: 结果 MUST 继续满足`slot-pose-result/2`旧必填字段和不变量；新增多候选、配对、
  模式和门控明细应作可忽略的诊断增量，除非书面兼容性评估证明必须升版。
- **FR-014**: 系统 MUST 为A2提供不含绝对数据路径的外置Manifest契约，记录数据集类别（正常/坏图）、
  相对路径、指纹、物理样品、条件组、采集时间/序号、重复序号和split。
- **FR-015**: Manifest条件组 MUST 由采集记录、可验证时间序列或显式映射提供；不得因正常集约500张
  就写死为25组×20张。
- **FR-016**: 角度truth CSV MUST 以图像指纹或稳定图像标识关联Manifest，并记录机械真值角、
  真值来源、标定版本、物理样品、条件组、重复序号和split；未知值显式为空。
- **FR-017**: 数据验证 MUST 阻止同一物理样品、同一原图或派生版跨development/tuning/validation/acceptance split，
  并检查Manifest与truth的指纹、分组和序号一致性。
- **FR-018**: 所有角度误差 MUST 使用环形差值；同条件静态重复性 MUST 基于有效角的环形展开/
  残差，失败样本单独统计，不得填0。
- **FR-019**: 不同真值角度组的跨组稳定性 MUST 对相对真值误差/残差的组统计进行比较，
  MUST NOT 对原始角度或原始角度组均值计算所谓“动态极差”。
- **FR-020**: 正常集报告 MUST 至少包含角度MAE/P95/max、有效数/率、各条件组静态极差、
  跨组残差统计、失败原因分布和耗时mean/P50/P95/max。
- **FR-021**: 坏图集报告 MUST 至少包含样本数、误引导/false-positive数与比率、失败原因分布和
  耗时mean/P50/P95/max；任何坏图`valid=true`均计为误引导。
- **FR-022**: 样本缺失、条件分组未确认、每个静态组少于20帧、真值缺失或验收阈值未确认时，
  报告 MUST 标为`INCOMPLETE`或`NOT_EVALUATED`，不得给出正式PASS。
- **FR-023**: 系统 MUST 提供Mac一键顺序：生成/验证Manifest、运行批量检测、校验truth、分别生成
  正常/坏图报告；路径由命令参数提供，不得写死服务器或Mac数据绝对路径。
- **FR-024**: 实现和验证 MUST NOT 修改`/home/ubuntu/disk/dzk/137-end-face-refactor-work`、
  `/home/ubuntu/disk/dzk/137壳体检测-孔2柱面和端面检测`或`/home/ubuntu/disk/gyj`下任何内容，MUST NOT 提交原图、压缩包或派生大图。
- **FR-025**: 本增量 MUST NOT 实现PLC写入或修改上位机；PLC地址、缩放、字节序、握手、超时和失败动作
  继续作为外部BLOCKED门。

### External Decision Gates / Blockers

- **B-001 目标实体语义**：生产引导对象是单个缺口、双缺口中哪一个，还是两缺口夹持的凸台/槽中心线，由机械方确认。
- **B-002 数据分组与工位映射**：A2正常/坏图的采集记录、条件组、物理样品、相机/工位/方向与历史参考图的映射，由数据负责人确认。
- **B-003 机械角契约**：机械零位、顺/逆时针正方向、图像到机械坐标映射和有效范围，由机械/机器人负责人确认。
- **B-004 质量验收门槛**：真实A2的角度MAE/P95/max、静态/跨组残差、有效率、坏图误引导率和节拍阈值，由质量负责人确认。
- **B-005 PLC/上位机契约**：字段、地址、缩放、字节序、握手、超时、过期判定和失败安全动作，由PLC/上位机负责人确认。

关闭顺序为B-001/B-002 → B-003 → 冻结Mac验证集 → B-004 → B-005。关闭前可输出数值诊断，
但正式引导角必须为空且`valid=false`。

### Key Entities

- **Angular Profile**: 环形外缘的角度强度/暗区剖面，绑定端面圆心、尺度、采样半径和品质。
- **Notch Candidate**: 一个环形暗区，包含角中心、半宽、显著度、起止边界、环绕标志和排名。
- **Notch Pair**: 两个候选的配对评估，包含间距、宽度/显著度比、质量得分、次优差距、
  唯一性和环形中心线角。
- **Diagnostic Mode**: 显式选择的`legacy_single_notch`或`paired_notches_centerline`，与生产语义确认状态分离。
- **A2 Manifest Record**: 外置原图的相对路径、指纹、数据集类别、样品、条件组、帧序号、重复序号和split。
- **Angle Truth Record**: 与Manifest图像关联的机械真值角、真值来源、标定版本和分组信息。
- **Evaluation Report**: 分开表达正常集精度/稳定性与坏图误引导的版本化报告。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 历史72角度合成扫角在`legacy_single_notch`下保持72/72有效，MAE不大于`0.3°`、
  P95不大于`0.5°`、最大误差不大于`0.8°`。
- **SC-002**: 受控paired正样本覆盖平移、缩放、亮度/噪声和`+179°/-179°`环绕，配对成功率100%，
  中心线环形MAE不大于`0.5°`且最大误差不大于`1.0°`。
- **SC-003**: 受控缺一槽、多余暗区、双配对歧义、裁切、错误配置和未确认机械语义样例100%
  fail-closed，正式角和置信度均为空。
- **SC-004**: 每个外缘候选的角中心、半宽、显著度、起止边界和环绕标志可在测试中数值核对，
  配对结果也可追溯到候选标识和最佳/次佳差距。
- **SC-005**: 现有v2契约、CLI、批处理和失败分支测试全部通过，旧消费者能忽略新诊断字段。
- **SC-006**: 服务器上单张不超过`5472×3648`的图像处理耗时P95不大于`8.0秒`，且批处理逐图失败
  不中断其他图像。
- **SC-007**: 外置Manifest和truth契约能识别100%的指纹/分组不匹配、物理样品跨split、重复/缺帧
  和少于20帧的静态条件组。
- **SC-008**: 正常集报告具有FR-020全部指标，坏图报告具有FR-021全部指标；不同真值组的跨组统计仅使用环形残差。
- **SC-009**: 代码库不新增A2原图、压缩包、派生大图或写死的Mac/服务器数据绝对路径，三个禁止修改目录的指纹保持不变。
- **SC-010**: 所有B-001至B-005未关闭时，默认配置对每个输入都不产生正式引导角、PLC编码或写入动作。

## Assumptions

- 本功能是`002-slot-pose-estimation`的增量，保留现有结果v2、只读历史资产校验和批处理框架。
- 多候选是对环形外缘notch剖面的最小增强，不是新建圆、全图配准或极坐标系统。
- A2原图只在Mac外置位置；服务器实现使用小型合成图和现有只读历史参考资产。
- 正常集约500张、坏图约201张仅是现场盘点，不作为编程常量或分组证据。
- 每个条件20帧是静态验收最小样本数；条件的实际起止仍来自采集记录或时序映射。
- 首版只输出绕A端面法向的一个带符号旋转角，不输出三维位姿、平移或尺寸OK/NG。
- 本增量不接入PLC、不修改上位机，也不替现场人员关闭任何机械、质量或控制契约。
