# Feature Specification: 孔2测量证据几何审计

**Feature Branch**: `main`

**Created**: 2026-08-15

**Status**: Audit contract closure implemented; server verification in progress

> **017 supersession**: 016的证据分层契约继续有效，但其早期参考资产描述只是历史。
> 自017起，运行时注册和测量都只使用`018e...`/`faf...`权威人工参考。

## Scope

审计并实现Phi12.2和尺寸7的物理测量对象、原始图像证据、拟合模型、最终尺寸值及交付可视化
之间的语义。实现不修改配置或既有质量门，不运行holdout调参，不把目标真值传入检测入口。

## Confirmed facts

- 历史实现曾使用77点LabelMe `linestrip`，该资产已被017完全退役。
- 用户确认的最新标准答案元数据中，Phi12.2是80点的一侧可见`linestrip`，尺寸7是2点`line`。
- 当前数值结果输出Phi圆心、半径、直径和按参考角度重采样的`supportPointsPx`；没有输出本张图
  实际命中的原始边缘点或连续可见角段。
- 当前两个报告工具忽略`supportPointsPx`，用圆心和半径生成LabelMe `circle`并画完整圆。
- 尺寸7检测内部拟合两条边界线，最终契约只输出它们与测量轴的两个交点；报告工具把两点连成
  一条线。这条线是尺寸连接线，不是两条被检测边界。
- 单图Phi直径误差只验证从人工弧拟合出的圆参数，不验证可见弧证据是否与人工`linestrip`一致。

## Drawing-confirmed physical definitions

- **Phi12.2**：大圆柱/圆形凸台的外轮廓直径。负责人最新确认：测量只需要人工标注语义
  对应的一侧连续可见外轮廓弧（历史字段名`reference_left`，现拍图上显示为下方弧）。
  内部可保留镜像侧质量诊断，但它不是第二个必须测量对象，不进入交付弧。
- **7**：大圆下方窄颈的宽度，即窄颈两条平行实际直边之间的垂直距离。两条边分别拟合，通过
  公法线/共同法向计算距离；显示时必须同时呈现两条边界和独立尺寸连接线。
- 图纸中的7.7、16.6、1、R1及其他尺寸不属于本轮目标，不得进入检测、排序或验收。

## Requirements

- **FR-001**: MUST分离`rawEdgeEvidence`、`fittedGeometry`和`measurementValue`三层。
- **FR-002**: Phi的原始交付证据MUST是本张目标图实际命中的单侧校准外轮廓弧点，
  并记录内点、极性、残差、角覆盖和连续段；不得用无图像命中的圆周采样点冒充
  原始证据。
- **FR-003**: Phi拟合层MAY保留圆心、半径和直径，但完整圆只能叫数学拟合模型，不能作为已
  检测轮廓。
- **FR-004**: Phi交付可视证据MUST只输出有边缘支持的单侧校准局部弧段；LabelMe使用
  `linestrip`，存在遮挡或角域断裂时继续拆分segments。默认预览和LabelMe不得画完整`circle`。
- **FR-004a**: 权威人工参考只给`reference_left`定义了亚像素边缘相位，因此当前数值圆和
  `evidenceComplete` 只依据该校准弧。`reference_right`可保留为内部质量诊断，但不得当作
  第二条交付测量弧，也不得拉动半径。
- **FR-005**: 尺寸7 MUST分别输出窄颈两条实际拟合边界的有限可见线段、各自原始边缘点和
  质量；通过共同法向计算两条平行线的垂距，两边界之间的测量连接线必须作为独立辅助对象。
- **FR-005a**: 两边可以先独立稳健拟合并验证平行度，再在原始内点支持下做共同方向的平行线
  拟合；不得用标称7把边线或输出距离拉向图纸值。
- **FR-005b**: 图纸7是窄颈实际外轮廓宽度。现拍剖面证明该轮廓在图像中形成有限宽暗边缘带；
  外、内两次相反梯度跃迁是原始光学证据，两者中点是底层物理轮廓的亚像素估计。不得把暗带
  最外梯度峰直接当零件边界，也不得丢失两次跃迁证据。
- **FR-006**: 若v6 fallback没有保留两条边界证据，交付层不得伪造边界线；必须标为
  `boundaryEvidenceUnavailable`，或先改造v6使其返回真实证据后才可显示。
- **FR-007**: 数值有效、证据有效和可视化可审计性必须分别报告；无证据区域不得外推成
  “已检测轮廓”。
- **FR-007a**: `measurementValid`保留既有数值质量语义。新增`evidenceComplete`、
  `evidenceAuditStatus`和`evidenceAuditReason`独立报告审核性：Phi有一条校准弧即`complete`，
  零弧为`unavailable`；D7两边证据俱全为`complete`，单边为`partial`，零边为`unavailable`。
  不得因为新审核字段而改写旧数值有效状态。
- **FR-008**: “检测失败”和“几何/显示语义错误”必须分别统计，不能靠修改门限解决显示错误。
- **FR-009**: 501、520、623、775、1331、1830、1835、1951必须进入定义确认后的复核矩阵；
  holdout不得用于调参。
- **FR-010**: MUST保持现有注册、Phi/D7质量门不变，先完成证据保留、几何契约和renderer；
  之后才能依据新证据诊断“检测不了”的原因。

## Explicit exclusions

本规格不检测或输出7.7、16.6、1、R1、Phi2/R2小耳尺寸，也不补全整个零件轮廓。完整拟合圆
不是检测轮廓，图纸标称12.2和7不得作为运行时像素补偿或候选拉回目标。
