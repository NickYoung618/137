# Feature Specification: 180°双拍槽姿态初版

**Feature Branch**: `023-half-turn-paired-guidance`
**Created**: 2026-08-17
**Status**: Clarified

## User Scenarios & Testing

### User Story 1 - 单图诊断与调整量（P1）

开发人员输入一个零件一个位置的单张检测结果，在完整真实槽可靠可见时得到当前角度及转到85°±5°的最短带符号调整量；检测失败时得到分层错误和空调整量。

**Independent Test**: 分别输入可靠完整槽、遮挡、歧义及圆失败结果，验证角度、方向和fail-closed。

### User Story 2 - 180°双拍互证与唯一调整量（P1）

同一零件在固定相机和夹具下拍摄两次，中间由外部硬件执行固定180°半圈旋转。软件一次接收两张结果，利用真实槽随零件转动、夹具阴影在相机坐标近似固定的规律进行互证，并只输出从第二拍当前位置到目标的一个调整量。

**Independent Test**: 用合成候选覆盖两拍完整、仅第一拍完整、仅第二拍完整、一真一假、固定阴影、矛盾及多解。

### User Story 3 - 可定位错误而不越权控制（P2）

开发人员能从输出看到每拍圆/槽状态、候选配对、180°归一化角、残差、选择来源和失败阶段；软件不判断硬件是否真正转准，也不产生PLC命令。

**Independent Test**: 每个失败分支都有稳定错误码、非空诊断证据且调整量为null。

## Clarifications

### Session 2026-08-17

- Q: 第二拍后是否回第一拍位置？ → A: 不回；直接从位置2执行最终调整。
- Q: 硬件是否返回实际旋转角？ → A: 不返回；软件按外部180°契约处理。
- Q: 是否保证至少一拍完整无遮挡？ → A: 是。
- Q: 只有一拍可靠时能否使用？ → A: 可以。
- Q: 相机和夹具是否固定？ → A: 是，只有零件旋转。
- Q: 最终目标属于哪个位置？ → A: 位置2当前图像坐标中的85°目标。
- Q: 接口形式？ → A: 初版同时支持单图和一次性双图输入；正式pairId接口预留。
- Q: 软件是否负责验证硬件180°？ → A: 否；只做图像证据一致性求证和错误定位。

## Requirements

### Functional Requirements

- **FR-001**: 系统 MUST 提供版本化的单图输入与双图输入契约；二者不得依赖绝对数据路径。
- **FR-002**: 双图输入 MUST 包含同一sampleId、唯一pairId、captureIndex 1/2、图像SHA-256及名义半圈契约。
- **FR-003**: 半圈契约 MUST 固定为180°且方向无关；顺时针180°与逆时针180°在几何归一化中等价。
- **FR-004**: 系统 MUST 把硬件完成180°视为外部输入责任；双拍不一致错误不得擅自诊断为硬件未转准。
- **FR-005**: 单图可靠时 MUST 输出当前角、目标85°、容差5°、最短调整量和方向；正为顺时针，负为逆时针。
- **FR-006**: 双图第一拍 MUST 只作为测量/互证来源；最终调整量 MUST 表示从第二拍当前位置到目标的旋转。
- **FR-007**: 两拍均可靠且一致时 MUST 使用第二拍直接测量计算调整量，禁止普通算术平均，第一拍只作互证。
- **FR-008**: 仅第二拍可靠时 MUST 使用第二拍直接测量；仅第一拍可靠时 MAY 按180°传播至第二拍，但 MUST 标识`CAPTURE_1_PROPAGATED_HALF_TURN`。
- **FR-009**: 真实槽跨帧匹配 MUST 使用环形差值、180°归一化、方形槽结构及现有单帧质量证据；不得按更接近85°或更小调整量挑选。
- **FR-010**: 固定相机坐标阴影不得因单个强梯度成为可执行槽；固定阴影在半圈归一化后不应满足真实槽运动规律。
- **FR-011**: 0个唯一解释、多解、两拍矛盾、两拍均遮挡、候选超限、输入/SHA错误 MUST fail-closed，调整量和方向均为null。
- **FR-012**: 一拍被判遮挡或错误时 MUST 保留其候选和拒绝原因，不得只丢弃角度值。
- **FR-013**: 80°至90°（含边界） MUST 输出调整量0和方向NONE；其余使用到85°的[-180°,180°]最短路径。
- **FR-014**: 精确180°调整的数值平局 MUST 采用确定性`+180/CLOCKWISE`显示约定；这不是PLC方向授权。
- **FR-015**: 所有双拍功能 MUST 默认关闭、developmentOnly、authoritative=false、posePromotionAllowed=false，PLC/mechanical command始终为null。
- **FR-016**: 现有paired v1、单图结果v2/v3、legacy/paired/multi-role/single_real_groove行为 MUST 保持兼容。
- **FR-017**: 没有真实同件180°图时，只能完成合成和契约初版，不得宣称现场有效率、准确率或硬件适配通过。
- **FR-018**: 输出 MUST 区分检测状态、互证状态、引导状态、选择来源、每拍角度、第二拍归一化角、配对残差和错误阶段。
- **FR-019**: 每次视觉算法修改 MUST 先用少量、按物理零件隔离且不含sealed test的真实样本复现问题，记录失败阶段和根因，再进入SpecKit修改；不得反复用全量数据调参。
- **FR-020**: 外圆或凹槽识别根因需要新视觉能力时，MUST 先只读审计yyh/gyj已有可用做法，优先复用其经验证的算法接口；复制或重写必须在规格中证明必要性。
- **FR-021**: 缺少足以裁决视觉语义的人工证据时 MUST 停止调参，并用通俗说明给出审核原因、代表图和最少操作步骤。

### Key Entities

- **Single Guidance Request**: 单拍图像身份及现有单帧结果。
- **Half-turn Pair Request**: 同件两拍、顺序身份和方向无关180°契约。
- **Pair Hypothesis**: 两拍候选、归一化角、残差、形状证据和失败检查。
- **Guidance Result**: 第二拍当前角、唯一调整量、方向、来源及非PLC安全边界。

## Assumptions

- 相机与夹具两拍之间固定，只有零件旋转。
- 硬件负责执行名义180°，软件不接收实际角反馈。
- 两拍至少一张具备完整可见真实方形槽；算法仍须独立证明该拍可信。
- 初版调用方一次提交两张，后续状态机接口不在本功能范围。

## Success Criteria

- **SC-001**: 单图和双图所有成功/失败Schema样例100%通过契约测试。
- **SC-002**: 正负半圈、0/360环绕、固定阴影、一拍可用、两拍可用、多解和精确180°均有确定性测试。
- **SC-003**: 所有失败测试100%满足调整量null、方向null、PLC null且错误阶段可定位。
- **SC-004**: 两拍可靠时100%以第二拍直接角计算；仅第一拍可靠时100%明确标记传播来源。
- **SC-005**: 默认配置下双拍功能100%不输出有效引导；旧paired v1聚焦测试无回退。
- **SC-006**: 全量测试、全部根Schema、CLI帮助、diff及大文件/路径污染检查通过。
- **SC-007**: 在没有真实同件180°样本时，发布材料明确标记`REAL_PAIR_VALIDATION_MISSING`。
- **SC-008**: 每个视觉变更证据均能追溯到“小样本复现→根因→SpecKit变更→小样本验证→独立回归”的顺序。

## Out of Scope / Blocked

- **BLOCKED-001**: 尚无同一物理零件旋转180°前后的真实图片，现场双拍效果未验证。
- **BLOCKED-002**: pairId尚未由上位机实际提供；本规格只固化接口。
- **BLOCKED-003**: PLC地址、缩放、字节序及执行授权不在本功能范围。
- **BLOCKED-004**: 硬件180°执行精度和反馈不由本软件判断。
