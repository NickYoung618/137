# Feature Specification: 孔2数据无关工程基础

**Feature Branch**: `main`
**Created**: 2026-08-13
**Status**: Implemented baseline

## User Scenarios & Acceptance

### 外置数据可验证

算法工程师可在服务器或Mac对同一外置图片目录生成/验证Manifest，清单包含相对路径、分组、
图像属性和SHA-256。缺图、篡改、重复序号或非20张分组必须明确失败。

### 重复性可离线计算

算法工程师可从测量CSV按样品和位置计算静态重复性，并从各位置均值计算动态重复性。
无`mm_per_px`时只能输出像素，不得给出毫米档位PASS。

### 现有孔2算法可冒烟

现有`hole_2/main.py`可在固定依赖环境中处理参考图，按双边界语义输出稳定的`d7_length`，
并同时输出`Phi12_2_r`和`Phi12_2_diameter_px`；参考图只有一张时重复性必须标记
`INCOMPLETE`。

## Requirements

- **FR-001**: 原图必须外置且不得提交Git。
- **FR-002**: Manifest必须使用相对路径并包含SHA-256、尺寸、格式、样品、位置和重复序号。
- **FR-003**: 数据验证必须默认重算SHA-256并验证每组期望图片数。
- **FR-004**: 静态统计必须包含n、均值、样本标准差、6σ、极小、极大和极差。
- **FR-005**: 动态统计必须对同一样品的各位置均值计算相同统计量。
- **FR-006**: 配置必须表达`mm_per_px`、特征映射、显式直径列、公差和重复性档位。
- **FR-007**: 未确认公差或标定不得产生正式OK/NG。
- **FR-008**: 已知损坏的直径标签必须映射到稳定输出列。
- **FR-009**: 尺寸7必须独立检测并拟合两个端点对应边界，不得把端点投影到同一检测线。
- **FR-010**: `ψ12.2`必须保留LabelMe `linestrip`来源和圆拟合质量追溯字段。

## Success Criteria

- **SC-001**: 合法临时数据集通过Manifest生成和全哈希验证；篡改可被发现。
- **SC-002**: 单元测试覆盖Manifest、校验、静态/动态重复性和标签适配。
- **SC-003**: 参考图冒烟在30秒内完成并生成测量CSV及重复性JSON/CSV。
