# Feature Specification: 现拍样品姿态注册与孔2尺寸检测

**Feature Branch**: `main`

**Created**: 2026-08-14

**Status**: Implemented (including 2026-08-14 controlled measurement hardening)

**Input**: 使用既有孔2检测能力和旧参考资产，对约旋转 90° 的现拍样品进行可信姿态注册，检测尺寸 `7` 与 `Φ12.2`，并在不把现拍标注作为运行时输入的前提下提供目标图坐标结果和离线真值对照。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 可信注册现拍样品 (Priority: P1)

算法工程师以旧参考图片、旧参考标注和一张现拍图片为输入，获得包含方向、尺度、旋转、平移和质量状态的姿态注册结果。系统必须在多个可能方向中选择与主壳体多处几何结构一致的候选，并拒绝只在背景或少数局部区域相关的假匹配。

**Why this priority**: 姿态错误会使后续所有孔2尺寸落到背景或错误零件上，是检测可信性的前置条件。

**Independent Test**: 使用不带现拍标注的现拍图片运行注册；结果必须选择与实际约 90° 姿态一致的离散方向，输出可逆映射、多个独立几何支持和明确质量状态。用合成旋转、尺度、平移及干扰背景样例可独立验证正确候选胜出、假匹配被拒绝。

**Acceptance Scenarios**:

1. **Given** 旧竖向参考和约旋转 90° 的现拍主壳体，**When** 执行姿态注册，**Then** 系统从至少四个正交方向候选中选择一个候选，再完成小角度、尺度和平移精配准，并记录候选排序与质量依据。
2. **Given** 背景区域产生较高单一相关响应，**When** 该区域不能同时解释多个分散参考特征，**Then** 系统拒绝该候选而不是输出可信注册。
3. **Given** 所有候选均不满足质量门限，**When** 注册结束，**Then** 系统输出不可判定状态和具体失败原因，不生成伪造的尺寸值。

---

### User Story 2 - 输出孔2尺寸与目标坐标映射 (Priority: P2)

算法工程师在可信注册基础上复用既有孔2检测，获得 `7` 和 `Φ12.2` 的像素几何、逐特征质量状态以及可直接叠加到现拍图片上的目标坐标；原有参考坐标系业务列继续保留。

**Why this priority**: 目标坐标使现场标注和算法结果能够审计，兼容列则避免现有消费方因升级失效。

**Independent Test**: 对已知相似变换的合成几何运行完整检测，验证参考坐标业务列不变、目标坐标可由同一注册映射重建且正逆映射误差不超过 0.25 px。

**Acceptance Scenarios**:

1. **Given** 可信注册和可检测的两个尺寸特征，**When** 完成检测，**Then** 输出 `7` 的两个目标图端点、长度和质量字段，以及 `Φ12.2` 的目标图圆心、半径、直径、圆弧支撑点和质量字段。
2. **Given** 现有消费者仍读取参考坐标业务列，**When** 使用新输出，**Then** 既有列名与参考坐标语义保持兼容，新目标坐标字段不会覆盖旧值。
3. **Given** 某一特征检测失败，**When** 输出结果，**Then** 该特征保持独立无效状态和失败原因，另一特征及注册状态不被篡改。
4. **Given** `Φ12.2` 主搜索在半径比 `0.88` 下界饱和，**When** 该下界命中被确认，**Then** 系统才单次执行下界 `0.84` 的恢复搜索并记录 `candidate_recovery_pass=expanded_radius`；其他失败不得触发。
5. **Given** 新切线双边界检测失败，**When** v6 原始双边界结果的上游质量状态和有限量测均通过，**Then** 才可回退并显式记录来源；否则尺寸7保持无效。

---

### User Story 3 - 外置真值离线验收 (Priority: P3)

算法工程师可在检测完成后，用独立验收工具读取检测结果和负责人确认的现拍 LabelMe JSON，计算 `7` 端点/长度和 `Φ12.2` 圆弧/拟合直径的直接对照误差。验收工具必须证明真值未进入算法运行时输入。

**Why this priority**: 单图结果只有在坐标一致、来源可追溯且未发生真值泄漏时才具有审计价值。

**Independent Test**: 先只用旧参考资产与目标图片生成检测结果，再以结果文件和外置真值运行验收；报告必须包含输入哈希、算法/契约版本、目标坐标误差和“仅单图、非重复性/生产合格判定”声明。

**Acceptance Scenarios**:

1. **Given** 负责人确认且哈希匹配的外置图片与 JSON，**When** 执行离线验收，**Then** 报告校验两个哈希，只接受 `7` 两点线与 `Φ12.2` 77 点折线，并输出逐项像素误差。
2. **Given** 真值 JSON 被误传给检测入口，**When** 参数解析发生，**Then** 检测入口拒绝未知真值参数，运行时输入清单中也不得出现目标标注。
3. **Given** 单张现拍图验收完成，**When** 汇报结果，**Then** 报告明确限定为单图证据，不推导 20 张重复性、毫米精度或生产 OK/NG。

### Edge Cases

- 现拍图宽高与旧参考对调、尺寸不同，且主壳体只占画面部分区域。
- 0°/90°/180°/270° 中两个方向得分接近，无法形成足够候选间隔。
- 相位相关峰落在黑色背景、高纹理背景或邻近工件，但分散几何支持不足。
- 参考锚点部分出画、遮挡或局部边缘低对比，导致部分特征不可用。
- 精配准求得异常尺度、角度、平移，或正逆变换不一致。
- 姿态注册有效但 `7` 或 `Φ12.2` 仅一个检测失败；必须分离注册与测量状态。
- 外置图片或真值哈希不符、标签数量/类型/点数不符、结果契约版本不支持。
- 只有单张验收图，不能据此声明重复性、泛化能力或生产公差结论。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 系统 MUST 复用现有孔2 v6 检测能力及旧参考图片/旧参考 LabelMe 标注，不得用现拍真值替换参考模型或重写整套检测。
- **FR-002**: 系统 MUST 对每张目标图评估至少 `0°`、`90°`、`180°`、`270°` 四个离散方向候选。
- **FR-003**: 每个方向候选 MUST 继续估计受限的小角度、尺度和平移精配准，并输出从参考坐标到目标坐标及其逆映射。
- **FR-004**: 候选选择 MUST 同时使用至少三个空间分散的几何支持及其残差/可见性，不能只依赖相关峰或两个局部锚点。
- **FR-005**: 系统 MUST 为方向候选记录方向、精配准参数、支持特征数、空间覆盖、残差、图像一致性得分、有效状态和失败原因。
- **FR-006**: 系统 MUST 通过版本化质量门限限制尺度、小角度修正、候选间隔、多特征支持、空间覆盖和几何残差，并在不满足时安全失败。
- **FR-007**: 注册有效状态 MUST 与 `7`、`Φ12.2` 的各自测量有效状态分离，任何失败不得被改写为有效或默认合格。
- **FR-008**: 注册无效时系统 MUST 不输出有限的最终尺寸测量值，并保留诊断数据。
- **FR-009**: 系统 MUST 保留现有参考坐标系业务列的名称和语义，新字段不得覆盖旧列。
- **FR-010**: 系统 MUST 为 `7` 输出目标图两端点及长度，为 `Φ12.2` 输出目标图圆心、半径、直径和用于检测的圆弧支撑坐标。
- **FR-011**: 系统 MUST 在输出中声明所有坐标字段的坐标系、单位、图像尺寸及变换方向。
- **FR-012**: 检测运行时 MUST 只接受旧参考资产、目标图片和版本化配置；现拍 LabelMe JSON 不得成为算法输入、候选打分或回退依据。
- **FR-013**: 系统 MUST 提供独立离线验收工具，读取已生成结果与外置真值，严格校验输入 SHA-256、标签、形状类型和点数后计算像素误差。
- **FR-014**: 离线验收 MUST 对 `7` 计算无序端点匹配误差和长度误差，对 `Φ12.2` 计算真值圆拟合、预测圆几何误差及真值点到预测圆的残差。
- **FR-015**: 每次检测和验收 MUST 输出算法版本、配置版本、契约版本、参考资产哈希、目标图片哈希、耗时及失败原因。
- **FR-016**: 外置图片、现拍标注、原始结果和运行输出 MUST 保持在 Git 之外；仓库只允许代码、规格、契约、测试和不含私有坐标的说明。
- **FR-017**: 单图报告 MUST 明确不是 20 张重复性、毫米精度或生产 OK/NG 证据；未确认生产标定和公差时不得给出这些结论。
- **FR-018**: 系统 MUST 提供可在服务器和 Mac 上以外置路径运行的单图检测与离线验收命令。
- **FR-019**: 单图验收报告 MUST 在同一契约中汇总选择方向、正/逆变换、所有候选分数及拒绝原因、逐特征质量状态、`7` 目标端点/长度误差与 `Φ12.2` 圆心/直径/径向残差。
- **FR-020**: 技术质量状态 MUST 只有在注册和两个特征都通过各自门禁时才为完整；任一失败时 CLI MUST 以非零状态结束并保留显式失败原因，不得输出生产 OK/NG。
- **FR-021**: 系统 MUST 提供 Mac 外置批量回归入口，可分组处理正常品和坏品目录，将逐图 JSONL 与按组质量统计写入仓库外，运行时不读取目标标注。
- **FR-022**: 必须在外置确认单图上执行完整检测→冻结结果→LabelMe 验收测试；测试资产缺失时可显式 skip，不得改用合成图声称真实证据。
- **FR-023**: `Φ12.2` MUST 先以固定下限 `0.88` 执行主半径搜索；仅当主候选命中该下界饱和时，才以固定下限 `0.84` 执行一次恢复搜索，不得全局放宽主搜索。
- **FR-024**: `Φ12.2` 质量证据 MUST 记录主下界是否饱和、主/最终半径比和恢复通道；扩展搜索再次饱和或未过原质量门时 MUST 保持无效。
- **FR-025**: 尺寸7新切线双边界失败后，仅当现有 v6 结果为有限几何且 `d7.quality.upstream=ok:dual_boundary_fit` 时 MUST 允许回退，并记录 `candidate_fallback_pass=v6_original_quality`；不得改写 v6 原诊断或放宽注册主门限。
- **FR-026**: 外置负责人确认单图验收 MUST 要求尺寸7长度绝对误差不超过 `2 px`、`Φ12.2` 直径绝对误差不超过 `1 px`；真值路径仅是可选外置验收输入。

### Key Entities

- **旧参考模型**: 由旧参考图片、旧参考标注、特征几何和资产哈希构成，是运行时唯一的标注来源。
- **方向候选**: 一个离散方向及其精配准、支持特征集合、空间覆盖、质量指标和拒绝原因。
- **姿态注册结果**: 被选择候选的可逆坐标变换、候选排序、总体质量状态与版本信息。
- **孔2测量结果**: `7` 与 `Φ12.2` 在参考/目标坐标系中的几何、独立有效状态和逐特征诊断。
- **离线验收报告**: 将不可变的检测结果与外置真值进行对照的像素误差、哈希及证据范围声明。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 四个正交方向及其精配准均被评估并可审计；在合成已知变换测试中，正确方向 100% 被选中，含强背景干扰的假匹配 100% 被拒绝。
- **SC-002**: 在合成有效样例中，参考到目标再到参考的映射误差不超过 `0.25 px`，恢复尺度误差不超过 `0.5%`、角度误差不超过 `0.25°`、平移误差不超过 `1.0 px`。
- **SC-003**: 所有注册失败、部分测量失败、哈希错误和真值结构错误样例均返回明确不可判定/无效状态，且不产生伪造有限尺寸或生产合格结论。
- **SC-004**: 既有孔2回归测试及参考图冒烟全部通过，旧参考坐标业务列保持兼容。
- **SC-005**: 负责人确认的单张现拍图可在不向算法提供目标 JSON 的情况下完成注册与检测，并生成严格哈希校验的目标坐标验收报告；报告列出 `7` 与 `Φ12.2` 的实际像素误差而不隐去失败。
- **SC-006**: 仓库自动化检查确认没有图片、现拍标注、JSONL、运行输出或大于 1 MiB 的新增文件进入 Git。
- **SC-007**: 服务器外置确认单图 E2E 测试严格校验图片/标注 SHA、`270°` 方向、技术质量完整及当前冻结像素回归界限，并证明目标 JSON 不在运行时输入中。
- **SC-008**: Mac 批量入口可对 `normal`/`defective` 两组外置图片产生总数、注册/逐特征/技术完整计数、方向分布、候选/特征失败原因和耗时统计。
- **SC-009**: 交付前确认 `origin=https://github.com/NickYoung618/137.git`，排除图片/JSONL/大文件后将完整增量提交并推送到 `main`；远端有竞争变化时先 fetch/rebase 且保留双方改动。
- **SC-010**: 单元测试可重现主下界饱和触发恢复、非下界失败不触发、扩展下界再饱和不误恢复，以及 v6 原质量通过/拒绝两类回退。
- **SC-011**: 外置确认单图 E2E 在不将目标 JSON 传入检测器的前提下，尺寸7长度误差 `≤2 px`、`Φ12.2` 直径误差 `≤1 px`；资产缺失时显式 skip 并报告限制。

## Assumptions

- 本功能只覆盖负责人已确认的孔2对象 `7` 和 `Φ12.2`；其他孔2标注仍可由 v6 保留，但不纳入本轮现拍验收。
- 旧参考资产继续来自既有受控目录并按当前记录哈希校验；现拍 JSON 只供最终离线验收。
- 本轮以像素几何和坐标映射评估算法，不提供未确认的毫米标定、公差或生产 OK/NG。
- 单张现拍真值用于证明流程和报告真实性，不足以证明跨样品泛化或重复性。
- 外置真值只用于离线验收，不进入运行时。若验收揭示坐标/尺寸语义错误，修正必须可由旧参考几何和目标像素独立推导，禁止硬编码真值坐标；配置冻结后重新执行并如实保留前后验收结论。
