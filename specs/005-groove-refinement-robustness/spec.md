# Feature Specification: 槽壁亚像素精修稳定性

**Feature Branch**: `003-a2-paired-notch-stability`

**Created**: 2026-08-15

**Status**: Ready for Planning

**Input**: User description: "在004全画面找圆完成后，按优先级改进真实槽两侧壁的亚像素精修，恢复3张因入口圆角/局部纹理导致直线残差过大的真实A2诊断样本，但不放宽质量门、不伪造人工truth，并保留静态重复性和fail-closed验收。"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 从局部干扰中唯一恢复真实槽壁 (Priority: P1)

作为姿态算法验收人员，我希望精修器在槽口圆角、加工纹理或少量错边使侧壁点不完全共线时，找到跨足够径向深度的唯一直线主体，再与物理外圆求交得到槽口中点角。

**Why this priority**: 当前25张A2 JPEG的圆定位和真实槽识别均为25/25，但第23～25张均因同一侧槽壁的结构化离群点返回`GROOVE_REFINEMENT_FAILED`，是当前最直接的下游瓶颈。

**Independent Test**: 用可控的直槽壁加入口圆角、底部圆角、孤立错边和纹理假边，只有在直线主体唯一且同时通过内点数、内点率、径向覆盖、残差和外圆交点门时才输出精修角。

**Acceptance Scenarios**:

1. **Given** 一侧槽壁中间存在唯一长直线主体，两端含圆角或少量假边，**When** 执行亚像素精修，**Then** 系统排除离群点并仅用通过质量门的直线主体求外圆交点。
2. **Given** 两组不同直线都具有接近的支持度，**When** 无法唯一选择槽壁，**Then** 系统返回明确歧义失败，不强选一条线。
3. **Given** 最佳直线的内点率、径向覆盖或最终P95残差不合格，**When** 完成评估，**Then** 系统保持精修失败且不回退到粗角度。

---

### User Story 2 - 对每张真实图解释精修依据 (Priority: P2)

作为人工复核人员，我希望看到每侧原始边缘点、保留内点、拒绝点、直线主体、外圆交点、最佳/次佳差距和失败理由，以便判断算法是否真的跟随物理槽壁。

**Why this priority**: 只将成功率从22/25改成25/25不能证明精度；必须让所有过滤与唯一性证据可视化、可复算。

**Independent Test**: 在已知内点/离群点的合成样例和3张现场失败JPEG上生成诊断，确认统计数量、比例、覆盖、残差、交点和选择结果一致。

**Acceptance Scenarios**:

1. **Given** 精修成功，**When** 生成JSON和叠加图，**Then** 每侧都明确区分全部支持点、内点、拒绝点和最终直线。
2. **Given** 精修失败，**When** 生成诊断，**Then** 保留已计算的候选证据和稳定失败码，不用空泛的“失败”覆盖原因。

---

### User Story 3 - 保留已通过样本和安全契约 (Priority: P3)

作为维护人员，我希望新策略是显式版本化的增量能力，使已通过的22张、历史模式、顶层v2和PLC安全边界均不回退。

**Why this priority**: 工业精修不能以提高通过数为理由改变旧算法含义或降低安全门。

**Independent Test**: 同一批图分别运行旧策略和新策略；旧版结果保持可重现，新版对旧成功帧的角差受控，所有不可测结果仍为空角度和`valid=false`。

**Acceptance Scenarios**:

1. **Given** 配置选择旧策略版本，**When** 重放历史测试，**Then** 旧拟合、阈值和输出保持不变。
2. **Given** 新策略对某侧无法找到唯一高质量直线，**When** 输出姿态结果，**Then** 正式机械角为空、`valid=false`，不采用粗候选中心代替。

### Edge Cases

- 槽壁两端都有圆角，但中间仍有足够长的直线主体。
- 局部反光产生与真槽壁平行的第二条边。
- 离群点数较少，但集中在外圆交点附近。
- 直线内点数达标但只覆盖很短的径向区间。
- 两个不同直线模型支持度接近。
- 单侧成功、另一侧失败或交点不靠近粗边界。
- 槽口跨越0度/360度环绕边界。
- 新策略在JPEG诊断副本上成功，但原始BMP或人工truth缺失。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 系统 MUST 在亚像素边缘点与外圆交点之间增加版本化的槽壁直线共识识别，且不改变上游真实槽候选。
- **FR-002**: 新策略 MUST 使用确定性候选生成和排名，同一输入/配置不得因随机种子产生不同结果。
- **FR-003**: 每个侧壁模型 MUST 输出检测点数、内点数/比例、拒绝点数、纵向覆盖率、残差、直线参数、最佳/次佳支持度和唯一性差距。
- **FR-004**: 系统 MUST 同时校验最少内点数、最小内点率、最小径向覆盖、最终P95残差和外圆交点与粗边界的环形角差。
- **FR-005**: 系统 MUST 聚类几何等价的直线假设，并对几何不同的最佳/次佳模型执行显式唯一性门。
- **FR-006**: 无合格共识、候选不唯一、支持覆盖不足、直线残差过大或外圆交点异常时 MUST 返回稳定失败检查项，精修角保持空。
- **FR-007**: 新策略 MUST 沿用现有亚像素边缘采样、物理外圆和严格2 px P95直线残差门，不得通过放宽该门恢复3张图。
- **FR-008**: 旧`groove-sidewall-subpixel-v1`策略 MUST 可显式复现；新策略 MUST 使用新阈值版本和向后兼容诊断字段。
- **FR-009**: 角度 MUST 继续由两侧精修直线与同一物理外圆的交点环形中点得到，不得使用暗区加权中心或85度目标反向修正检测角。
- **FR-010**: 只有两侧槽壁都通过新质量门时才能产生图像测量角；任一侧失败 MUST 阻止85度质量判定和机械纠偏。
- **FR-011**: 审阅产物 MUST 在Git外用不同颜色显示全部侧壁点、内点、拒绝点、直线和外圆交点，并在CSV/JSON汇总通过/失败原因。
- **FR-012**: 25张JPEG的新策略结果 MUST 与旧策略成对报告；对旧成功帧报告环形角差，对旧失败帧只报告几何一致性，不包装成真值精度。
- **FR-013**: 每个进入精度或静态重复性统计的真实样例 MUST 继续具有同图人工外圆和真实槽标注；缺少时必须标记`NOT_EVALUATED`。
- **FR-014**: 静态重复性 MUST 继续仅使用明确的同样品/同工位/同条件分组和“检测角-人工真值角”环形残差，不得将第23～25张直接当作已确认重复组。
- **FR-015**: PLC地址、缩放、字节序和握手未确认期间，顶层正式机械角 MUST 保持为空且`valid=false`。
- **FR-016**: 实现 MUST 增加受控测试，覆盖入口/底部圆角、孤立离群、结构化错边、双直线歧义、短覆盖、弱边、单侧失败、交点越界和0度环绕。
- **FR-017**: 实现 MUST 复跑全量单元、Schema、CLI、legacy 72角、paired、全画面圆定位、1真槽+2阴影、人工BMP开发对照和25张成对诊断。

### Key Entities

- **Sidewall Point Set**: 一侧槽壁的亚像素边缘点及对应径向采样位置。
- **Sidewall Consensus Hypothesis**: 一个确定性直线假设、内点集、覆盖、残差、外圆交点和排名证据。
- **Sidewall Selection Decision**: 最佳/次佳假设、唯一性差距、接受状态和失败检查。
- **Refined Groove Opening**: 两侧唯一直线与物理外圆的交点、开口宽度、环形中点和质量状态。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 在25张外置A2 JPEG开发诊断上，新策略保持圆定位25/25和“1个真槽候选+2个阴影拒绝”25/25，槽口亚像素几何从22/25提升到25/25。
- **SC-002**: 新策略对旧策略已通过的22张，精修槽口中点的环形角差P95不超过0.05度、最大不超过0.10度。
- **SC-003**: 新恢复的3张中，每张精修中点与原始粗候选中心的环形差不超过0.30度，3张精修中点极差不超过0.10度；该结论仅标为无真值开发一致性。
- **SC-004**: 合成的双直线歧义、短覆盖、弱边和单侧失败样例100%安全失败，且精修角为空。
- **SC-005**: 每个侧壁诊断都能复算检测点、内点、覆盖、残差、最佳/次佳差距和最终交点，25/25有叠加图和CSV/JSON记录。
- **SC-006**: 同一服务器上新策略批量检测的完整单图P95仍不超过2.5秒、峰值内存仍不超过1.5 GiB，且精修阶段新增P95不超过50 ms。
- **SC-007**: 全量单元和契约测试通过，legacy 72角、paired、全画面圆定位、旧版精修和PLC空正式角契约无回退。
- **SC-008**: 当真实图缺少同图人工truth或静态分组时，精度和静态重复性均为`NOT_EVALUATED`，不将新增通过帧包装成生产准确率。
- **SC-009**: Git污染检查确认没有图像、标注truth、绝对数据路径或大文件进入提交。

## Assumptions

- 第23～25张的中间直线支持是可用的算法候选证据，但在人工同图槽边界完成前不是正式truth。
- 新策略只修改真实槽已唯一识别后的侧壁直线选择，不修改全画面圆定位、暗区候选或真槽/阴影过滤。
- 85度正负5度、左下位置门和图像Y轴下半轴基准保持不变；PLC输出映射仍属于外部阻塞。
- 25张JPEG只是开发诊断；正式精度和静态重复性验收继续依赖原始BMP、同图人工标注和明确采集分组。
