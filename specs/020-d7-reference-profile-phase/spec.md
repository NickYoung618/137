# Feature Specification: D7参考剖面相位候选

**Feature Branch**: `main`

**Created**: 2026-08-17

**Baseline**: `2341ba482473ceea5db35a64015a8eb9dd819525` plus uncommitted, verified Spec 019 increment

**Status**: Complete; diagnostic candidate only, not promoted to formal D7

## User Scenarios & Testing

### User Story 1 - 复用已验证的双边缘方法 (Priority: P1)

算法开发人员希望复用服务器现有算法中经过验证的灰度剖面、极性、亚像素定位和多扫描稳健拟合思想，
但不能把其他工位的物理对象、固定阈值、标称值或像素补偿直接搬入孔2 D7。

**Why this priority**: 019已经消除了约317px的单梯度错层，但581/582仍显示约304px结果相对人工距离
偏大3.80--6.60px，说明剩余问题是边缘层身份/相位而非重复性。

**Independent Test**: 在包含更强邻层的图像中，候选依据权威参考剖面上下文选择与人工模板相同的边缘层，
而不是选择绝对梯度最大的邻层。

**Acceptance Scenarios**:

1. **Given** 正确边缘层梯度较弱但其完整剖面上下文与权威参考一致，**When** 生成候选，
   **Then** 候选选择正确层并记录剖面相似度、极性和跨扫描支持。
2. **Given** 邻层更强但上下文或极性顺序不同，**When** 生成候选，**Then** 邻层不得仅凭峰值强度胜出。
3. **Given** 没有唯一且一致的匹配层，**When** 生成候选，**Then** 候选必须显式失败。

### User Story 2 - 区分候选研究与正式测量 (Priority: P1)

审核人员希望在目标坐标人工线尚未上传时继续研究候选，但正式D7值和有效状态不能被未经坐标级验证的
候选覆盖。

**Independent Test**: 对相同输入启用候选诊断前后，正式D7数值、有效状态、Phi结果和质量门逐值一致；
新增字段只描述独立候选。

**Acceptance Scenarios**:

1. **Given** 参考剖面候选生成成功，**When** 输出当前结果，**Then** 正式D7仍来自019已审计路径，
   候选仅以独立诊断状态出现。
2. **Given** 候选失败，**When** 正式019路径有效，**Then** 候选失败不得清空正式D7。
3. **Given** 581/582只有总距离而无D7-A/B坐标，**When** 汇报研究结果，**Then** 不得宣称已定位具体失败侧。

### User Story 3 - 坐标级人工边界审核 (Priority: P2)

收到外置LabelMe坐标后，审核人员可以比较人工D7-A/B与候选的外过渡、中点、内过渡和拟合线，
确定误差来自哪一侧以及哪一层。

**Independent Test**: 使用小型LabelMe夹具和冻结后的正式/候选结果，输出每侧到人工线的垂距、最近证据层和总长度误差；
工具不得读取标称毫米值或修改算法结果。

### Edge Cases

- 权威参考剖面缺失、越界或局部对比度退化时，候选必须失败。
- 两个不同层的相似度接近且不能唯一判断时，不得用人工总长度破除歧义。
- 581/582人工总距离只能离线报告，不能反求单侧位置。
- 同一物理组人工距离存在约2.872px差异时，应报告人工复核重复性风险，不能选择更有利的一张。
- Phi算法、注册、配置、Schema及既有质量门不在本增量修改范围。

## Requirements

### Functional Requirements

- **FR-001**: MUST记录yyh/gyj可复用方法、不可复用物理对象与依赖边界。
- **FR-002**: MUST从唯一权威018e/faf参考中提取D7-A/B局部归一化剖面，不得使用退役模板。
- **FR-003**: 候选MUST联合使用完整剖面相似度、梯度极性顺序、成对过渡和跨扫描一致性。
- **FR-004**: 候选MUST以亚像素方式定位，并分别稳健拟合两条边界后计算公法线距离。
- **FR-005**: MUST拒绝无唯一层、低支持、低相似度、残差或平行度不满足既有门的候选。
- **FR-006**: MUST保持正式D7/Phi/registration及其valid状态逐值不变；本阶段候选不得晋级为正式输出。
- **FR-007**: MUST输出独立候选状态、失败原因、每侧支持、相似度、位移离散度、残差、平行度和证据点。
- **FR-008**: 离线审核工具MUST接受权威参考、目标图及可选外置LabelMe JSON；MUST先冻结正式结果和候选，
  再逐侧比较，且不得把目标真值作为运行时输入。
- **FR-009**: MUST禁止硬编码297.1722、300.0442、304、317、7或任何固定像素补偿。
- **FR-010**: MUST不引入OpenCV；只复用项目已有Pillow/NumPy数学能力。
- **FR-011**: MUST测试更强邻层、错误极性、歧义层、低对比度、坐标反变换和正式输出不变。
- **FR-012**: MUST在权威同图及仓库外581/582图像上生成诊断；无人工坐标时只报告候选，不宣称精度通过。

### Key Entities

- **Reference profile model**: 权威参考图中人工边界法向的归一化灰度/梯度上下文与人工相位。
- **Profile-phase candidate**: 目标图中与参考上下文匹配的单侧亚像素边界假设。
- **Candidate audit**: 两侧证据、拟合几何、质量字段以及与正式D7相互独立的状态。
- **Truth-side comparison**: 外置人工D7-A/B线与候选证据层的离线距离比较。

## Success Criteria

- **SC-001**: 合成更强邻层测试100%选择参考上下文一致层，歧义/错误极性测试100%拒绝。
- **SC-002**: 权威同图候选两侧到人工线误差均不超过2px，且不改变正式结果。
- **SC-003**: 581/582均产生可审计的每侧剖面候选或明确失败，且不会利用人工总距离选择候选。
- **SC-004**: Spec 019的030组重复性、9帧状态和Phi逐值保持不变。
- **SC-005**: 全套测试、compileall、Schema、SpecKit分析和仓库数据审计通过。

## Assumptions

- 当前581/582图片和D7-A/B LabelMe JSON均在服务器仓库外，并已冻结SHA。
- 逐侧证据足以定位两帧各自的相位，但两帧B侧相位不一致，不足以定义统一运行时规则。
- 候选晋级为正式D7仍需要能跨冻结验证集成立的图像证据规则，属于后续明确任务。
