# Research: D7参考剖面相位

## R1 - 服务器可复用实现审计

**Decision**: 复用方法而非复制模块。

**Evidence**:

- yyh与gyj的旧`algorithms/hole_2/main.py` SHA一致；标签7仍走普通线检测，不是窄颈双边界垂距。
- yyh/gyj `algorithms/side_length/main.py`提供多像素投影、相反极性边缘和亚像素灰度交点。
- gyj `HousingInspectionDemo/algorithms/b_end_face/main.py`提供成对边缘、多扫描、自适应支持和共同拟合。
- 当前Spec 019已实现NumPy/Pillow版成对过渡、多扫描和稳健直线，缺口是边缘层身份。

**Rejected**:

- 直接复制旧孔2：没有正确D7物理语义。
- 复制side_length的8%阈值和校准偏移：对象不同，构成固定经验值/像素补偿。
- 复制B端面OpenCV径向圆环代码：依赖和几何对象均不匹配。

## R2 - 根因边界

**Decision**: 将剩余问题定义为“层选择”和“人工相位定位”两个待证假设。

**Evidence**:

- 权威同图人工A/B与成对过渡中点分别相差约0.16px和0.81px，说明参考域中点语义成立。
- 581/582正式候选约303.77/303.84px，静态变化仅0.07px，但相对人工总距离偏大6.60/3.80px。
- 只有总距离无法分解A/B误差，因此不能断言是哪侧或该取外峰/中点/内峰。

## R3 - 候选评分

**Decision**: 使用完整局部灰度上下文和梯度上下文的归一化相关，辅以极性、最佳/次佳margin及跨带MAD。

**Rationale**: 绝对最强梯度会选到邻层；完整上下文能辨别正确层两侧的材料/暗带结构，归一化相关降低亮度变化影响。

**Alternative rejected**: 用581/582人工总距离选择更接近的候选；这会把目标真值注入算法决策。

## R4 - 晋级策略

**Decision**: 020只交付独立诊断候选，正式D7保持019。

**Rationale**: 581/582坐标JSON尚未在服务器，无法验证每侧误差；直接晋级违反安全失败和可追溯要求。

## R5 - 人工标注重复性

**Decision**: 报告581/582人工总距离差2.872px，不据此判定任一标注错误。

**Rationale**: 2px验收门小于该差异，后续需对同一帧重复盲标或增加少量冻结验证标注，量化人工不确定度。

## R6 - 581/582逐侧相位审核（T019）

**Decision**: 不把020参考剖面候选或固定的外峰/中点/内峰相位晋级为正式D7。

**Evidence**:

- 外置真值SHA固定为581=`8b9b505b...08dc6`、582=`22bdadd6...33bc`；工具先冻结正式结果和
  020候选，之后才在离线比较阶段读取真值。
- 当前正式成对过渡中点相对人工总宽误差为581=`6.602123px`、582=`3.798799px`；020全剖面
  候选误差反而为`12.939874px`和`10.109635px`，所以相关分数、支持和残差通过不能证明层身份。
- A侧人工相位中位数为581=`0.6404`、582=`0.6022`；两帧均以中点层最接近人工线，误差中位数
  `1.9339px`和`1.4759px`。
- B侧不是同一种相位：581人工相位中位数=`0.8156`，内过渡比中点更近（`2.5595px`对
  `4.3355px`）；582人工相位中位数=`0.6100`，中点比内过渡更近（`1.4296px`对`5.0071px`）。
- 581/582来自同一20帧静态组，但人工宽度相差`2.8720px`，且B侧相位差约`0.206`。把任一帧
  反推的固定相位写入运行时会直接过拟合另一帧。

**Consequence**: 证据足以定位581偏差主要来自B侧人工线更靠内过渡、582则仍以中点最接近；证据
不足以形成不依赖真值的统一运行时规则。019的同语义成对中点与安全拒绝保持不变。
