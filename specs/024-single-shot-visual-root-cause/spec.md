# Feature Specification: 单拍视觉分层根因诊断

**Feature Branch**: `024-single-shot-visual-root-cause`
**Created**: 2026-08-17
**Status**: Diagnostic-first

## User Scenarios & Testing

### User Story 1 - 少量代表图分层诊断（P1）

开发人员从同一批非封存真实数据中选取成功及每类失败代表，不跑全量，即可获得外圆候选、物理圆、真槽过滤、唯一性、槽壁精修和同源性各阶段的证据及叠加图。

**Independent Test**: 145/147和141/161/441/281/261/401/374均能归入唯一失败层并生成Git外审阅产物。

### User Story 2 - 复用验证算法再修复（P1）

若根因属于圆或凹槽视觉能力，开发人员先只读核对yyh/gyj已有方法，记录可复用点和差异；只有证据证明适用，才建立实现任务并用按物理零件隔离的小样本验证。

**Independent Test**: 每个算法变更都有复现样本、根因、复用来源、反例、回归样本和人工门。

### User Story 3 - 合并后不依赖其他项目源码（P1）

部署人员只拉取本仓库即可加载已审计的A端面核心实现，不需要服务器上另一个gyj/yyh代码目录。参考标注和参考图仍作为受控部署资产在Git外按SHA校验。

**Independent Test**: 在不存在`/home/ubuntu/disk/gyj`的隔离临时环境中，适配器仍从本仓库唯一核心模块完成函数库存和SHA校验；核心SHA不符时在图像检测前fail-closed。

## Requirements

- **FR-001**: 诊断集 MUST 只含少量非sealed代表，禁止用700张循环调参。
- **FR-002**: 成功代表 MUST 包含145/147；失败代表 MUST 覆盖141/161圆候选缺失、441物理圆残差、281真槽零接受、261真槽多接受、401槽壁精修、374混合阴影。
- **FR-003**: 每图 MUST 输出原图相对身份、错误码、失败阶段、关键门指标、候选叠加图和联系表，媒体留Git外。
- **FR-004**: 不得把AUTO叠加解释为人工真值或准确率。
- **FR-005**: 圆问题 MUST 先只读审计gyj外缘射线、robust/geometric circle fit及yyh相近方法；槽问题 MUST 先审计其边缘/轮廓做法。
- **FR-006**: 不得复制两套算法；可复用能力应通过适配或调用现有实现接入。
- **FR-007**: 根因未由图像或人工语义裁决时 MUST 停止修改，并给用户最少审核问题及操作步骤。
- **FR-008**: 每轮修改后先重跑对应物理零件小样本，再跑独立分组与全量单元测试。
- **FR-009**: 所有失败继续fail-closed；不得为提高valid率放宽门限。
- **FR-010**: 024不得修改main、PLC/HMI或读取sealed part-006。
- **FR-011**: 可合并运行路径 MUST 从本仓库内唯一的A端面核心模块加载代码，不得依赖gyj/yyh绝对源码路径。
- **FR-012**: 本地核心模块 MUST 保留上游gyj SHA溯源及本地SHA校验；不符时 MUST 在执行视觉算法前返回`ASSET_MISMATCH`。
- **FR-013**: 历史外部源文件配置 MUST 保持向后兼容，但不得作为可移植默认；参考图/标注仍须Git外供应并校验SHA。

## Success Criteria

- **SC-001**: 9张代表100%生成可解码叠加图、联系表、review JSON和候选CSV。
- **SC-002**: 9张代表100%具有明确阶段分类，空调整角保持null。
- **SC-003**: 首轮只读诊断完成前核心算法和阈值零修改。
- **SC-004**: 任何后续修改均能证明一个已复现根因被解决且至少一个反例仍fail-closed。
- **SC-005**: 仓库内核心模块加载、函数库存和错误SHA三类测试100%通过，且测试路径不存在gyj/yyh目录。

## Blocked

- **BLOCKED-001**: 代表图没有新增像素级真值；AUTO结果不能裁决圆边/槽壁精度。
- **BLOCKED-002**: 若叠加图无法判断物理语义，需要用户进行最小人工确认后才能修改。
