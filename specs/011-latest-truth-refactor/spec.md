# Feature Specification: 孔2最新唯一真值边缘语义重构

**Feature Branch**: `main`

**Created**: 2026-08-15

**Status**: In implementation

## Context

负责人指定仓库外 `端面标注样品.json` 为孔2当前唯一单图标准答案；对应图片与标注
SHA-256 分别为 `faf357c2e6e8e58d667f76a3d9ed4f4d51ab4d451c2661cf0efbc641405b2d8b`
和 `018e3449c051c15f7946315bd0d7f21cd79f4d4983efca0d11c7d98f02bfffa6`。
旧审核标注只保留历史对照，不再作为精度门。

无目标标注运行的真实基线为：注册有效、方向270；尺寸7预测 `317.563069 px`，
对最新真值 `310.001991 px` 的长度误差 `7.561078 px`；`Phi12.2` 预测直径
`539.151976 px`，对最新真值 `541.130081 px` 的直径误差 `1.978106 px`。

## Clarified measurement semantics

- 尺寸7对应连接臂上下两条黑色物理轮廓带的中心线间距；每侧必须由相反极性的成对
  梯度共同确定轮廓中心，不能只取轮廓带外侧的单个强峰。
- `Phi12.2` 对应大圆外轮廓从暗侧进入外侧亮平台的正极性物理边缘。边缘相位从旧参考
  图及旧参考标注的局部灰度过渡自动估计，目标真值不得参与运行时估计。
- 当前目标标注只允许离线诊断和验收工具读取。检测 API、配置和结果的 `runtimeInputs`
  不得包含目标标注。

## User stories

### US1 - 可追溯边缘诊断

算法工程师可在仓库外生成真值/预测叠加图，以及尺寸7正负梯度峰对和 Phi 径向灰度
剖面，从具体物理边界解释误差来源。

### US2 - 尺寸7轮廓中心检测

检测器在多个局部平行扫描位置寻找顺序一致、极性相反的成对边缘，稳健拟合上下轮廓
中心线，并通过跨带支持、平行度、残差、峰值及配对宽度质量门。

### US3 - Phi 外物理边缘检测

检测器明确使用参考定义的径向极性、参考图导出的边缘相位和受控角覆盖产生多圆候选，
通过稳健拟合及既有半径/中心/覆盖门选择外物理边缘。

### US4 - 一键单图验收

使用者可给出旧参考标注、旧参考图、目标图、最新真值和外置输出目录，得到检测结果、
验收报告、关键指标、日志、退出码及清楚的 PASS/FAIL。

## Functional requirements

- **FR-001**: MUST 保留现有四方向注册、条件恢复、v6质量门和几何一致性诊断。
- **FR-002**: MUST NOT 修改 `algorithms/hole_2/main.py` 的复用 v6 核心。
- **FR-003**: 尺寸7 MUST 将相反极性的有序边缘对转换为物理轮廓中心点，不得加入固定像素补偿。
- **FR-004**: 尺寸7 MUST 记录每侧配对支持数、两种极性峰、配对宽度、拟合残差、平行度和失败侧。
- **FR-005**: 尺寸7新候选失败时，仍只允许通过原质量门的 v6 结果回退；失败不得伪装有效。
- **FR-006**: Phi 主候选 MUST 在选择中实际执行参考径向极性，不得只记录极性名称。
- **FR-007**: Phi 边缘相位 MUST 从旧参考图片与旧参考标注的灰度过渡推导，不得读取目标真值、标称12.2或目标文件名/hash。
- **FR-008**: Phi 多圆候选 MUST 通过原半径界、中心界、极性、角覆盖、边缘支持和稳健残差门。
- **FR-009**: `0.88→0.84` 两阶段半径恢复及其他按饱和维度恢复 MUST 保持受控，不得全局放宽。
- **FR-010**: 检测入口和 `runtimeInputs` MUST 禁止目标标注；目标标注只由离线工具读取。
- **FR-011**: 最新真实 E2E MUST 冻结两个外置资产哈希；尺寸7长度误差 `<=2 px`，Phi直径误差 `<=1 px`。
- **FR-012**: 旧单图只作历史报告，不得阻断最新定义。
- **FR-013**: 单图验收脚本 MUST 无本机绝对路径，并保存 stdout、stderr、退出码、起止时间、算法结果、验收报告和 key metrics JSON/TXT。
- **FR-014**: 所有图片、LabelMe、JSONL、叠加图、剖面与运行输出 MUST 保持 Git 外置。
- **FR-015**: 9帧控制帧500/521/620不得新增注册或两特征失效。
- **FR-016**: Mac 2000正常图最终门为 registration `>=1962`、尺寸7 `>=1863`、Phi `>=1922`，且比例离群不得增加。

## Success criteria

- **SC-001**: 外置诊断报告明确显示尺寸7旧峰与最新轮廓中心的关系，以及 Phi 旧候选的极性/相位/圆拟合偏差。
- **SC-002**: 最新 SHA 锁定真实 E2E 同时满足两项像素误差门。
- **SC-003**: 9帧诊断集控制帧无新增失效，逐图旧/新状态与数值差可审计。
- **SC-004**: 全套 unittest、compileall、Schema、SpecKit analyze 和 Git 大文件/媒体门禁通过。
- **SC-005**: Mac 2200张批量命令可复现，最终接受仍由 Mac 全量证据决定。
