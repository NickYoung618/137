# Feature Specification: 孔2批量诊断与定向恢复

**Feature Branch**: `main`

**Created**: 2026-08-14

**Status**: In progress

## Context

Mac 外置 2200 张回归的正常组基线为：registration `1962/2000`、尺寸7
`1863/2000`、`Φ12.2` `1922/2000`。失败按连续批次聚集，且双特征有效结果仍存在
`7/Phi` 几何比例离群。原图、JSONL 和批量输出保持 Git 外置。

## User stories

### US1 - 可追溯失败维度

算法工程师能从结果直接看到注册的具体门限维度、`Φ12.2` 的半径/中心边界与
极性/角覆盖、尺寸7的失败侧与扫描条带点数/残差/峰值，不改变当前有效判定。

### US2 - 受控注册恢复

只有 primary 返回 `no_valid_candidate` 才执行对比度归一化/稳定轮廓多证据重试；
恢复候选仍必须通过原支持数、覆盖、残差、尺度和角度门。

### US3 - `Φ12.2` 按饱和维度恢复

半径下界继续使用 `0.88→0.84`；中心边界使用强环形边缘重定中；上界/弱边缘使用
有极性、角覆盖和稳健残差门的多圆候选。

### US4 - 尺寸7多平行扫描带

多条平行扫描带独立产生两侧边界，稳健聚合后同时门禁跨条带一致性、平行度、
残差和边缘峰值；保留原 v6 质量回退。

### US5 - 错边风险诊断

`7/Phi` 只可使用旧参考几何和图像证据进行排序、离群诊断或拒绝，不得把输出拉向
标称比值。

## Functional requirements

- **FR-001**: 诊断增量 MUST 不改变现有判定、变换或量测值。
- **FR-002**: 注册候选 MUST 为每个支持/总体门限记录值、边界与 passed。
- **FR-003**: `Φ12.2` MUST 记录半径上/下界、中心 x/y 边界、边缘极性和角覆盖。
- **FR-004**: 尺寸7 MUST 记录 p1/p2 扫描条带的可用 profile、边缘点、残差、峰值和失败阶段。
- **FR-005**: 离线工具 MUST 统计连续失败、显式重复组和 `7/Phi` 离群。
- **FR-006**: 重复组 MUST 来自 Manifest 或显式组大小，不得由文件名推断 20 帧。
- **FR-007**: 全量脚本 MUST 接受五个外置路径，保存日志/时间/退出码/关键统计，不读目标标注。
- **FR-008**: 注册恢复 MUST 只在 `no_valid_candidate` 后触发，`ambiguous_candidates` 不得降低 margin。
- **FR-009**: 注册恢复 MUST 通过全部原几何质量门。
- **FR-010**: `Φ12.2` 恢复 MUST 依饱和维度分支，禁止全局扩大搜索。
- **FR-011**: `Φ12.2` 多圆候选 MUST 通过极性、角覆盖和稳健残差门。
- **FR-012**: 尺寸7多带聚合 MUST 通过跨带一致性、平行度、残差和峰值门。
- **FR-013**: 尺寸7 MUST 保留 v6 原质量回退且不改写原诊断。
- **FR-014**: 几何比例 MUST 只用于排序/诊断/拒绝，不得校正输出。
- **FR-015**: 新有效结果 MUST 记录 `sourceDetector`、`recoveryPass` 和 `quality`。
- **FR-016**: 负责人单图 MUST 继续满足尺寸7 `≤2 px`、`Φ12.2` 直径 `≤1 px`。
- **FR-017**: 控制帧 500/521/620 主路径与变换 MUST 不回归。
- **FR-018**: 原图、批量汇总、JSONL 和运行输出 MUST 保持 Git 外置。

## Success criteria

- **SC-001**: 9 帧诊断集可输出逐图旧/新状态与数值差。
- **SC-002**: 纯诊断版对9帧的状态、变换和量测值零变化。
- **SC-003**: 控制帧不触发恢复，且变换在数值容差内不变。
- **SC-004**: 外置单图精度门和全套自动化门通过。
- **SC-005**: Mac 2200 张复验无新增正常图回归，且比例疑似离群数下降（由 Mac 最终验收）。
