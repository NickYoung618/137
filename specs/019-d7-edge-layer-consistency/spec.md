# Feature Specification: D7边缘层一致性诊断与定向恢复

**Feature Branch**: `main`

**Created**: 2026-08-17

**Baseline**: `2341ba482473ceea5db35a64015a8eb9dd819525`

**Status**: Implemented and verified

## User Scenarios & Testing

### User Story 1 - 识别D7真实边界层 (Priority: P1)

审核人员希望D7主路径失败后，恢复结果仍然代表图纸定义的窄颈上下外轮廓，
不能因为另一层梯度更强就跳到邻近边缘。

**Why this priority**: 030组已证明单梯度恢复可以质量门全部通过，但产生约317px的
错边缘层，属于“有效但语义错误”风险。

**Independent Test**: 使用含一个主导成对过渡层和少数干扰层的图像证据，验证输出只来自
主导成对过渡层，且所有原质量门仍通过。

**Acceptance Scenarios**:

1. **Given** 主路径成对过渡点中有少数邻近边缘层干扰，**When** 初次直线拟合因残差或方向失败，
   **Then** 只可用成对相反极性过渡中点做稳健重拟合，并重新通过原质量门。
2. **Given** 没有主导边缘层或原支持数/残差/方向/平行度门不通过，**When** 尝试恢复，
   **Then** D7必须显式失败，不得用单个最强梯度伪恢复。

### User Story 2 - 保持既有测量语义与追溯 (Priority: P2)

诊断人员能从结果区分初始成对拟合、边缘层稳健重拟合和多带恢复，并看到为何接受或拒绝。

**Independent Test**: 分别构造初次成功、稳健层恢复成功和无主导层失败三种结果，核对来源、
恢复步骤、原始/内点数和失败原因。

**Acceptance Scenarios**:

1. **Given** 初次成对拟合已通过，**When** 输出D7，**Then** 数值、来源和证据不发生变化。
2. **Given** 稳健层重拟合被使用，**When** 输出D7，**Then** 质量字段必须记录原始点、采信点、
   重拟合前失败阶段与最终原门结果。

### Edge Cases

- 两个边缘层支持接近，无法证明主导层时必须拒绝。
- 成对过渡支持数不足时不得改用单边梯度。
- 稳健重拟合后残差或平行度仍不通过时保持无效。
- Phi有效性、数值和证据不得受本增量影响。
- 100张无真值图只能评价状态、路径一致性和静态重复性，不得宣称绝对准确度。

## Requirements

### Functional Requirements

- **FR-001**: MUST把Mac提供的581/582人工公法线距离仅作为离线边缘层语义证据，不得进入运行时。
- **FR-002**: MUST区分单图人工对照与030组20张无真值重复性，不得将后者当准确度。
- **FR-003**: D7恢复MUST保持“成对相反极性过渡的物理轮廓中点”语义，不得用单个最强梯度替代。
- **FR-004**: 稳健重拟合MUST只在初次成对拟合失败后尝试；初次已有效的帧MUST保持原输出。
- **FR-005**: MUST复用现有支持数、3px残差、轴向、平行度和搜索边界质量门，不得修改配置或门限。
- **FR-006**: 没有唯一可支持层或原质量门未全通过时MUST拒绝，不得伪造D7有效。
- **FR-007**: MUST记录是否尝试/使用边缘层稳健重拟合、初始失败阶段、原始/采信点数和原门验证结果。
- **FR-008**: MUST不修改Phi、D7配置、质量门、标称值或任何固定像素补偿。
- **FR-009**: MUST用合成多层、单层、对等歧义层和证据不足测试覆盖安全失败。
- **FR-010**: MUST在仓库外复测581/582、030组20张、9帧development/diagnostic和权威同图；禁止读取holdout调参。
- **FR-011**: MUST保持权威同图D7误差不超过2px、Phi直径误差不超过1px，且Phi逐值不变。
- **FR-012**: MUST通过全套单测、compileall、JSON Schema、SpecKit analyze、diff和大文件/运行产物审计。

### Key Entities

- **Paired transition evidence**: 同一扫描剖面上相反极性的外/内过渡及其物理轮廓中点。
- **Edge layer hypothesis**: 由多条扫描剖面中彼此一致的成对过渡中点形成的候选直边层。
- **D7 audit evidence**: 原始点、采信点、拟合线、原质量门结果及恢复路径。

## Success Criteria

### Measurable Outcomes

- **SC-001**: 581保持主路径和原D7数值，不因新恢复逻辑变化。
- **SC-002**: 582不再以单梯度多带路径输出约317px；只有成对过渡证据通过所有原门时才可有效。
- **SC-003**: 030组不再出现“304px主语义/317px单梯度语义”的检测路径双峰。
- **SC-004**: 合成测试对无主导层、对等歧义层和原门不通过的候选保持100%拒绝。
- **SC-005**: 9帧的注册和Phi状态不退化；权威同图精度门继续通过。

## Assumptions

- Mac提供的581/582人工公法线距离真实反映其LabelMe中D7-A/D7-B两条线；服务器不伪造该JSON。
- 两张小样本足以否定317px边缘层，但不足以证明其他无真值帧的绝对精度。
- 本增量的目标是边缘语义一致与安全失败，不是把输出拉向人工距离。
