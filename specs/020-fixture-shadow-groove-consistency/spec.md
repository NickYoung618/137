# Feature Specification: A2固定阴影与真槽同源性

**Feature Branch**: 020-fixture-shadow-groove-consistency
**Created**: 2026-08-16
**Status**: Implemented as default-off experiment; Mac truth and performance gates blocked

**Input**: 根据480张normal历史记录中两处相机坐标固定阴影与随零件旋转的唯一真槽证据，建立默认关闭的固定阴影nuisance template、真槽双侧壁同源性门和槽/阴影重叠分解；禁止按固定角删除候选、禁止剩余候选猜槽、禁止放宽门限强行通过。

## Clarifications

### Session 2026-08-16

- 约31°和328°绝不能设为ignore mask或禁止检测区；真槽可能转到固定阴影位置，固定角只允许作为nuisance prior/template location。
- part-019实验20/20不是恢复成功；人工确认是真槽一侧与固定阴影另一侧的稳定错误配对，必须作为false-positive回归。
- 没有新人工标签时不能生产启用；灰度模板只能是默认关闭的诊断实验，等待Mac原始BMP配对验证和人工复核。
- normal:part-006继续封存；只可引用已暴露聚合摘要，不读取、不重跑、不调参。
- 现场新增观察认为两处固定装置阴影的位置大致固定，但其灰度、宽度、轮廓强度和整体外观可能因透视、
  拍摄角度及照明而不对称；该观察尚未由结构化标签证明。两阴影之间的相似性和配对完整性只能作为诊断证据，
  不得单独成为否定固定阴影假设或拒绝真槽的硬门。
- “固定阴影更像沿圆周延伸的圆弧、真实槽更像有直壁和明确端点的方形开口”是待6帧LabelMe验证的现场假设，
  不是已确认真值；验证前不得据此修改门限、默认启用实验或合入main。

## Evidence Basis

- 服务器从历史700图JSONL与009权威分组独立复算：排除normal:part-006后有480张normal；原始候选数0/1/2/3/4对应67/38/60/312/3张。
- 严格302帧中，阴影A中心中位31.394°、范围30.597°–31.837°；阴影B中位327.746°、范围326.374°–328.188°；第三候选中心跨1.763°–357.188°。
- 第三候选最小灰度亏损积分1176.796，高于严格302帧两个固定阴影最大值1105.338和1074.727。该间隔是当前证据，不是生产普适阈值。
- 现场给出的宽松统计365/413（88.4%）没有提供宽松角窗定义，只作支持证据，不进入实现阈值或验收准则。
- profile角以图像+x为0°、y向下，顺时针增加；固定阴影模型不得改写85°±5°闭环引导契约。
- Mac 140张原始BMP配对结果必须原样保留：019自动valid 33/140，020自动valid 0/140；part-019的20个
  已确认混合边被对比不对称门拦截，part-008的13个无真值拒绝不可判断正误，也不可用于宣称准确率提升。

## User Scenarios & Testing

### User Story 1 - 识别但不屏蔽固定阴影 (Priority: P1)

算法负责人需要把相机/夹具坐标下长期固定的两处阴影建模为可解释干扰，并看到每个候选与两个模板的位置、宽度、强度和局部结构证据，同时保留所有原始候选。

**Why this priority**: 两处阴影是固定且不可避免的主要假候选源，但按角度屏蔽会在真槽重叠时漏检。

**Independent Test**: 使用成对阴影、单处缺失、有限漂移、不相似假阴影和真槽恰好位于31°/328°的合成环形剖面，证明模板只产生nuisance证据而不删除候选。

**Acceptance Scenarios**:
1. **Given** 两处阴影成对出现，**When** 评估模板，**Then** 每处输出位置、宽度、亏损、灰度/梯度剖面子分和配对状态。
2. **Given** 只出现一处或两处不相似，**When** 评估模板，**Then** 不猜测缺失阴影，并输出不完整或不唯一；
   该状态本身不得否定固定阴影假设或直接拒绝候选。
3. **Given** 真槽位于31°或328°附近，**When** 评估模板，**Then** 保留候选进入重叠/同源性判断，不得按角度否决。

### User Story 2 - 拦截不同来源的混合双边 (Priority: P1)

姿态测量使用者需要系统证明槽口两条边属于同一个物理凹槽，避免将真槽一侧和固定阴影另一侧组成稳定错误角度。

**Why this priority**: part-019证明两边都强且直线稳定仍可能是假开口。

**Independent Test**: 用真槽双壁、阴影双边、真槽+阴影混合边、强度不对称、深度不一致、终点不一致和跨0°样例验证。

**Acceptance Scenarios**:
1. **Given** 两侧灰度跃迁、归一化剖面、深度、形态和终点一致，**When** 精修，**Then** 输出原始证据、归一化证据、阈值余量和通过状态。
2. **Given** 一侧是真槽壁而另一侧是阴影边界，**When** 评估同源性，**Then** 必须拒绝且姿态和引导量为空。
3. **Given** 两侧均达到单边梯度门但任一同源必需项失败，**When** 精修，**Then** 返回明确失败项，不用综合分或跨帧稳定性掩盖。

### User Story 3 - 安全分解槽与阴影重叠 (Priority: P2)

算法负责人需要在真槽与固定阴影合并为宽暗区时，比较“两个固定模板预测信号+额外槽残差”和“纯阴影模型”，生成有上限的分解假设；只有唯一同源真槽证据完整时才输出角度。

**Why this priority**: part-015、part-021和part-022表明固定角窗加剩余候选规则会失败。

**Independent Test**: 在已知真槽和两阴影的合成环形数据上逐步增加重叠，检查模型残差、假设上限、唯一性和安全失败。

**Acceptance Scenarios**:
1. **Given** 真槽与一处阴影部分重叠且残差仍形成完整双壁，**When** 分解，**Then** 保留原候选、纯阴影预测、额外槽残差和假设来源。
2. **Given** 多个假设都通过或一个也不通过，**When** 唯一性评估，**Then** 输出AMBIGUOUS或FAILED，姿态和引导为空。
3. **Given** 候选仅因中心接近固定角，**When** 评估，**Then** 不得直接删除、拒绝或标为阴影。

### User Story 4 - 按零件验证并生成最小标注队列 (Priority: P3)

质量人员需要按完整物理零件验证假阳性拦截、重叠分解和无回退，并获得不预填算法真值的最小人工标注任务。

**Why this priority**: 历史算法输出不是真值；没有人工区分真槽与阴影时，通过数增加不能称为准确性提升。

**Independent Test**: 使用分组、源图哈希和历史诊断生成队列，验证part-006泄漏拒绝、指定零件数量和所需shape。

**Acceptance Scenarios**:
1. **Given** part-019已知混合配对，**When** 回归，**Then** 实验模式不得输出自动valid姿态。
2. **Given** part-015和part-021重叠候选，**When** 验证，**Then** 分开报告唯一分解、歧义、无解和无标签不可判定。
3. **Given** 最小队列，**When** 生成，**Then** part-019、015、021各至少2帧，每帧要求real_groove_boundary和两个fixture_shadow/occlusion区域。
4. **Given** 默认配置或旧配置，**When** 运行历史路径，**Then** 行为和输出契约保持不变。

### Edge Cases

- 真槽中心或槽口跨0°/360°时使用环形差值和环形中点。
- 真槽与阴影A/B中心重合、部分重叠或完全包含时不得使用固定角屏蔽。
- 两处阴影只出现一处、分裂或与边界合并时模板必须标记不完整。
- 圆定位或物理圆失败时不得启动阴影分解掩盖上游错误。
- 两侧边缘均强但归一化剖面差异过大时，不得依靠线残差或稳定性接纳。
- 真槽双侧壁同源性综合分达标但任一必需硬门失败时必须失败；该规则不适用于两处固定阴影彼此相似性。

## Requirements

### Functional Requirements

- **FR-001**: 系统 MUST 将原始暗区、固定阴影匹配、分解假设、真槽粗筛、双侧壁同源性和最终姿态建模为独立阶段。
- **FR-002**: 固定阴影模板 MUST 使用相机/夹具坐标，版本化两处阴影的中心角、半宽、显著度、亏损积分和局部灰度/梯度剖面。
- **FR-003**: 模板 MUST 定义有限漂移；单图匹配不得修改模板或跨图学习新位置。
- **FR-004**: 每个候选对每个模板 MUST 输出位置、宽度、显著度、亏损、原始/归一化灰度剖面、梯度剖面子分和综合分。
- **FR-005**: 系统 MUST 输出两阴影成对完整性和相似性的诊断；缺失、多解或不一致时不得猜测补齐，
  但配对不完整或彼此不对称 MUST NOT 单独成为固定阴影分类或姿态拒绝硬门。
- **FR-006**: 命中31°/328°或任何固定角窗 MUST NOT 单独导致删除、拒绝、ignore mask或真槽角输出。
- **FR-007**: 模板评估 MUST 保留所有原始候选，只生成nuisance假设和诊断角色。
- **FR-008**: 真槽同源性 MUST 同时评估两侧灰度跃迁方向/幅值、归一化局部剖面、径向深度、连续形态和终点结构。
- **FR-009**: 同源性每项 MUST 有版本化门限、实测值、余量和失败码；局部灰度/梯度剖面 MUST 保留为可审计输出。
- **FR-010**: 同源必需子证据 MUST 使用硬门，不得由其他高分平均抵消。
- **FR-011**: 混合双边在同源性未通过时 MUST 被拒绝，currentAngleDeg、correctionDeg和引导量为null。
- **FR-012**: 精修 MUST 保留两侧亚像素点、鲁棒直线、残差、覆盖、外圆交点及灰度/梯度证据。
- **FR-013**: 重叠时系统 MAY 比较纯阴影模型和“阴影预测+额外槽残差”模型，但 MUST 保留原候选、模型残差、来源和数量。
- **FR-014**: 分解假设数 MUST 有硬上限；超限、0个通过或多个通过时 MUST 安全失败。
- **FR-015**: 分解和同源性 MUST 只使用当前单帧及版本化模板，MUST NOT 依赖跨帧移动或稳定性判断真伪。
- **FR-016**: 固定位置、显著度或亏损积分 MUST NOT 单独充当真槽/阴影分类准则。
- **FR-017**: single-real-groove只有唯一候选通过粗筛、精修、同源性和唯一性时 MUST 输出姿态。
- **FR-018**: 0个、多候选、模板不完整不可判定或同源失败 MUST 输出分阶段错误码并fail-closed。
- **FR-019**: 新模式 MUST 默认关闭；旧配置缺少字段时 MUST 保持当前行为和结果。
- **FR-020**: 实验模式只能由独立版本化配置显式启用，输出 MUST 标记模板版本、门限版本和激活状态。
- **FR-021**: 配置 MUST 严格验证角度、漂移、剖面、相似性、上限和约束，错误配置在读图前拒绝。
- **FR-022**: 新诊断 MUST 向后兼容，不改变legacy、paired、multi-role和默认single-real-groove语义。
- **FR-023**: part-019已知混合配对 MUST 作为false-positive回归，实验模式不得输出自动valid姿态。
- **FR-024**: part-015/021 MUST 作为重叠验证组；无标签时不得把通过数增加称为修复。
- **FR-025**: part-008/009/014/023上游失败门 MUST 保持，不得被阴影模型覆盖。
- **FR-026**: 验证 MUST 按完整物理零件分折，不拆帧、不按表现选组。
- **FR-027**: 工具 MUST 在读取结果或图像前拒绝part-006及其源图SHA-256。
- **FR-028**: 标注队列 MUST 包含part-019/015/021各至少2帧，记录哈希、选择规则和3类shape。
- **FR-029**: 人工标签和历史算法输出 MUST NOT 进入生产运行时；真值只进入评估。
- **FR-030**: 历史JSON、服务器JPEG和Mac原始BMP验证 MUST 分开报告。
- **FR-031**: 报告 MUST 分开自动valid、人工可信、真槽识别、角度误差和引导可用性。
- **FR-032**: 本功能 MUST NOT 修改外圆基线、85°±5°语义、PLC/上位机或封存状态。
- **FR-033**: 图片、LabelMe、联系表、回放输出和现场绝对路径 MUST 留在Git外。

### Key Entities

- **Fixture Shadow Template**: 相机/夹具坐标下的版本化固定阴影先验及允许漂移和参考剖面。
- **Fixture Pair Evidence**: 两模板在当前单帧的匹配、完整性、相似性和失败证据。
- **Overlap Hypothesis**: 合并暗区的有上限分解，包含纯阴影预测、额外槽残差、边界和来源。
- **Sidewall Source-Consistency Evidence**: 两条精修边的灰度跃迁、剖面、深度、形态和终点同源证据。
- **Groove Decision**: 候选经过粗筛、精修、同源性和唯一性后的状态。
- **Annotation Queue Item**: 待人工标注帧，包含零件、哈希、选择规则和必需shape，不预填真值。

## Success Criteria

### Measurable Outcomes

- **SC-001**: part-019已知混合配对受控回归100%同源失败且不输出姿态或引导。
- **SC-002**: 合成真槽端点反转、跨0°、亮度缩放和有界噪声用例100%保持同源结论和环形中点。
- **SC-003**: 真槽+阴影混合边、阴影双边、不对称、深度不一致和终点不一致用例100%安全失败。
- **SC-004**: 成对阴影、单处缺失、漂移越界和不相似对均100%得到对应状态和子证据。
- **SC-005**: 真槽位于31°、328°及其邻域的测试100%保留原候选，不执行固定角删除。
- **SC-006**: 重叠分解原候选、模型残差、来源和数量100%可溯源；0解、多解和超限不输出引导。
- **SC-007**: 默认配置、旧配置及全部历史模式测试100%保持当前行为。
- **SC-008**: Schema、CLI、失败分支和诊断均有测试；非法配置在读图前拒绝。
- **SC-009**: 分组审计100%拒绝part-006 sampleId或封存SHA并防止零件跨purpose。
- **SC-010**: 标注队列包含part-019/015/021各至少2帧及哈希、规则和必需shape。
- **SC-011**: Mac原始BMP结构化人工真值验证前，不宣称指定组修复、准确率提升或生产可用。
- **SC-012**: 实验模式单图P95新增耗时不超过0.8秒、峰值内存不超过1.5 GiB；默认模式不执行额外计算。
- **SC-013**: 污染审计不发现A2媒体、LabelMe、运行输出、现场绝对路径或超限大文件。

## Assumptions

- 31°和328°暗区与相机/夹具坐标大致固定，但结构化人工标注前只作软诊断先验；两处阴影不假定彼此对称。
- 圆弧连续阴影与近方形真槽的形态差异只是假设，需在6帧标签上比较局部曲率、两侧壁平行性、角点/端点、
  径向深度、槽宽一致性以及灰度/梯度剖面后再决定是否进入后续实现。
- 亏损积分当前间隔只用于审计假设，不作为单特征生产门。
- 当前只有一张人工圆/槽标注，不足以作百分比准确率声明。
- 服务器可用历史JSON/CSV和25张JPEG；140张原始BMP已由Mac回放，但服务器仅收到统计，结构化人工真值仍缺失。
- 优先传统几何和灰度/梯度剖面，不引入训练模型或新生产依赖。

## Out of Scope and Blocked Decisions

- **OUT-001**: 不修改外圆定位、85°±5°目标、PLC或上位机。
- **OUT-002**: 不用训练模型、生成式补全或跨帧运动替代单帧判断。
- **OUT-003**: 不把700/140张回放称为严格未见准确率测试。
- **BLOCKED-B01**: 生产模板和门限等待part-019/015/021结构化标注。
- **BLOCKED-B02**: Mac原始BMP配对回放已完成；019/020合入main和实验生产启用仍等待6帧人工真值确认无混合配对。
- **BLOCKED-B03**: part-015/021无标签时正确性不可证明，必须保留fail-closed。
- **BLOCKED-B04**: 365/413宽松统计未给角窗定义，不得转成门限。
- **BLOCKED-B05**: “圆弧阴影与方形真槽”及两阴影非对称性等待6帧LabelMe验证；验证前不修改020门限和生产状态。
