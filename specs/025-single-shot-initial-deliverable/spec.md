# Feature Specification: 单拍槽姿态初版交付

**Feature Branch**: `025-single-shot-initial-deliverable`

**Created**: 2026-08-17

**Status**: In progress

**Input**: 初版只处理单张A端面图像；只有唯一真实方形凹槽完整、无遮挡且几何可信时才输出图像引导角，遮挡、阴影混边、歧义或外圆失败时明确报错。

## Clarifications

### Session 2026-08-17

- Q: 初版是否依赖同件180°双拍？ → A: 否，初版只需单拍；双拍接口保留但不是成功前提。
- Q: 凹槽被固定物遮挡时如何处理？ → A: 必须失败关闭，不恢复不可见槽壁，不输出当前角或调整角。
- Q: 检测到完整凹槽后是否需要输出调整角？ → A: 是，目栅为相对图像Y轴下半轴顺时针85°，容差±5°；顺时针为正，逆时针为负。

## User Scenarios & Testing

### User Story 1 - 完整真槽输出单拍引导 (Priority: P1)

操作人员提供一张A端面图像，系统拟合唯一物理外圆，从三处常见暗区中识别唯一真实方形凹槽，用同一开口的两侧壁和槽口端点计算当前角与最短调整角。

**Why this priority**: 这是初版唯一必须交付的业务价值。

**Independent Test**: 用已有人工语义确认的145/147作开发正例；两图均应输出约29.58°当前角、约+55.42°顺时针调整量，PLC命令仍为null。145仅用Git外独立人工真值评估几何误差，真值不进入运行时。

**Acceptance Scenarios**:

1. **Given** 外圆唯一且真槽两壁完整、同源、端点在真实外圆槽肩，**When** 单拍检测，**Then** `detectionStatus=DETECTED`、`valid=true`，输出当前角、目标角、最短有符号调整角和方向。
2. **Given** 当前角位于80°到90°，**When** 计算引导，**Then** 调整角为0°且方向为`NONE`。
3. **Given** 当前角不在容差内，**When** 计算引导，**Then** 输出到85°的最短环形差，正数为顺时针、负数为逆时针。

---

### User Story 2 - 遮挡、阴影与歧义失败关闭 (Priority: P1)

操作人员需要系统把“真槽只露一边”、“真槽边+固定物阴影边”、“多个可能槽”和“外圆不可信”报成可定位的检测失败，而不是错误角度。

**Why this priority**: 错误引导会导致设备朝错误方向旋转，风险高于保守报错。

**Independent Test**: 374已确认混合边负例始终无角度；合成测试覆盖单壁、双壁遮挡、0候选、多候选、阴影混边和外圆失败。

**Acceptance Scenarios**:

1. **Given** 任一真槽侧壁被固定物遮挡或不可见，**When** 单拍检测，**Then** 输出`GROOVE_PARTIALLY_OBSERVED`或等价版本化错误，当前角、调整角和方向全为null。
2. **Given** 候选的两边分别属于真槽和固定物阴影，**When** 检测，**Then** 输出`GROOVE_SOURCE_INCONSISTENT`，不得通过对比度放宽恢复姿态。
3. **Given** 0个或多个真槽候选，**When** 角色唯一性判定，**Then** 分别返回识别失败或歧义，不用阴影补齐。
4. **Given** 外圆候选不唯一、拟合失败或物理圆质量不足，**When** 单拍检测，**Then** 返回圆阶段错误且不执行槽角计算。

---

### User Story 3 - 小样本根因修复与可审计验收 (Priority: P2)

算法工程师每次只修复一类已确认根因，先用对应物理零件小样本证明修复，再用不同物理零件验证没有过拟合。

**Why this priority**: 现有700张已被查看过，不能用同一批图循环调参后宣称泛化。

**Independent Test**: 每个视觉修改都关联错误类、代表图、人工语义、可复用方法、独立物理零件回归和修改前后指标。

**Acceptance Scenarios**:

1. **Given** 错误根因未被人工或独立几何证据确认，**When** 尝试修改门限，**Then** 开发流程必须阻止修改并生成最小人工审核问题。
2. **Given** yyh/gyj已有可适用的圆拟合、边缘或轮廓方法，**When** 根因与其能力匹配，**Then** 复用已审计实现并在本仓库形成可合并代码，不引入运行时绝对路径依赖。
3. **Given** 修改解决了一个开发样本，**When** 进入验证，**Then** 至少一个不同物理零件的反例仍正确失败关闭，且不读取sealed part-006。

### Edge Cases

- 槽与固定阴影角度重合时，不能用固定角度ignore mask；若无法证明双壁同源必须失败。
- 槽口跨越0°/360°时，中点和差值必须用环形角计算。
- 候选得分相同或次候选差距不足时，不得任意选第一个。
- 旧角度、前帧角度、默认0°均不得用于失败填充。
- 输入无法解码、结果过期或配置/SHA不匹配时，必须在对应阶段失败。

## Requirements

### Functional Requirements

- **FR-001**: 初版 MUST 接受单张图像并独立返回一份版本化结果；双拍不得作为单拍成功前提。
- **FR-002**: 检测流程 MUST 保持“物理外圆→原始暗区→真槽识别→双壁/槽口精修→同源性→角度引导”的分阶段输出。
- **FR-003**: 仅当物理外圆唯一、真槽候选恰好1个、两侧壁完整且来自同一方形开口、槽口端点可信时，MAY 输出`valid=true`。
- **FR-004**: 任一侧槽壁被遮挡、不可见或只能从另一侧推测时，MUST 返回部分观测错误，不得补造第二壁。
- **FR-005**: 真槽壁与固定阴影边的混合配对 MUST 返回`GROOVE_SOURCE_INCONSISTENT`或更具体的版本化子错误，不得输出角度。
- **FR-006**: 0个真槽、多个真槽、多个同分配对和次候选差距不足 MUST 分别保持失败或歧义，不得用阴影凑数。
- **FR-007**: 当检测有效时，MUST 用`image-y-down-clockwise-signed/1`计算当前槽相对Y轴下半轴的有符号角，并用环形最短差计算到85°的调整量。
- **FR-008**: 当前角在[80°,90°]时，MUST 输出`correctionDeg=0`、`rotationDirection=NONE`；否则正数为`CLOCKWISE`、负数为`COUNTERCLOCKWISE`。
- **FR-009**: 检测失败时，`currentAngleDeg`、`correctionDeg`、`rotationDirection`和所有PLC/机械执行字段 MUST 为null，不得填0或复用旧值。
- **FR-010**: 图像引导量与PLC执行命令 MUST 分离；初版可输出图像引导，但PLC命令继续为null，不修改PLC/HMI。
- **FR-011**: 旧`legacy_single_notch`、`paired_notches_centerline`、`multi_notch_roles`和双拍试验接口 MUST 保持兼容，但不得主导单拍数据模型。
- **FR-012**: 运行时 MUST NOT 读取LabelMe、人工真值、sampleId特判、文件名特判或固定图像角度删除区。
- **FR-013**: 可视化 MUST 分别展示外圆、原始暗区、被拒阴影、最终真槽双壁/端点以及失败阶段，AUTO标记不得冒充人工真值。
- **FR-014**: 每次视觉修改 MUST 在SpecKit中记录根因、数据分组、复用来源、门限版本、修改前后指标、反例和人工门。
- **FR-015**: yyh/gyj只读审计后的可复用方法 MUST 以本仓库可合并的唯一实现或适配形式交付，不得在部署时依赖其绝对路径。
- **FR-016**: 不得读取sealed part-006调参，不得使用700张循环调参后宣称泛化或准确率。
- **FR-017**: 输出必须通过Schema、CLI、失败分支、环形角和静态重复性测试，并报告单图耗时P50/P95/max。

### Key Entities

- **SingleShotRequest**: 一张图像的任务身份、相对路径、图像SHA、配置版本与时间语义。
- **StageEvidence**: 外圆候选、物理圆质量、原始暗区、真槽候选、双壁精修、同源性与唯一性证据。
- **SingleShotGuidance**: 检测状态、引导状态、当前角、目标角、容差、调整角、方向与无效原因。
- **ReviewDecision**: 对代表图的物理语义回答；它只作离线证据，不是运行时输入。

## Success Criteria

### Measurable Outcomes

- **SC-001**: 145/147在显式单拍初版配置下100%输出非PLC图像引导；145候选角对已有独立人工角误差维持不大于5°。
- **SC-002**: 374和所有合成遮挡/混边/单壁/多解反例100% `valid=false`，当前角、调整角、方向和PLC全为null。
- **SC-003**: 141/161/441/281/261/401每图100%保留唯一、可追溯的失败阶段；未经人工语义确认前不强行提升为有效。
- **SC-004**: 环形角、±180°、80/90边界、顺逆时针、检测失败和无PLC映射的聚焦测试100%通过。
- **SC-005**: 每个已确认视觉根因修改后，开发零件组和至少一个不同物理零件验证组均通过，并报告失败分布与静态重复性。
- **SC-006**: 全量单元测试、所有根Schema、`git diff --check`和大文件/绝对数据路径污染检100%通过。
- **SC-007**: 单图耗时在同机成对基准中不回退，总P95不高于2.5秒，且不因新增判定重复解码原图或重复完整外圆链。

## Assumptions

- 每件只有1个真实方形凹槽，常见的另外2处暗区由固定装置/遮挡阴影产生。
- 目标图像引导契约已确认：图像x向右、y向下，以Y轴下半轴为0°，朝左下顺时针85°±5°。
- 145/147的完整真槽语义确认和374的混边负例语义保持有效；AUTO线不自动升为像素真值。
- 当前700张已被查看，因此它们是开发/回归证据，不是严格未见测试。

## Resolved Human Semantic Evidence

- **HUMAN-001**: 用户确认141/161/441叠加图中显示的三条圆边均属于真实壳体圆边。这证明图中存在真实圆结构，不等于其中任意一条都可以替代契约中的物理外圆。
- **HUMAN-002**: 281的`candidate-002`不是真实凹槽，而是固定装置阴影；当前`GROOVE_RECOGNITION_FAILED`不应通过放宽宽度变化门恢复。
- **HUMAN-003**: 261的`candidate-004`是真实凹槽，`candidate-006`是固定装置阴影。该语义可用于离线诊断阴影为何过门，禁止按候选编号做运行时特判。
- **HUMAN-004**: 401真实凹槽的两侧槽壁不完整可见；当前`GROOVE_REFINEMENT_FAILED`与初版“遮挡必须失败”相符，不应修复成有效角。

## Remaining Evidence Boundary

- 141/161/441已解决“是否存在真实壳体圆边”的语义问题，但仍需用现有射线点簇和拟合诊断区分“射线在多条同心真实边之间切换”、“候选定位偏差”与“物理圆残差门过严”；在没有这项根因证据前不得直接放宽圆门。
- 人工结论是离线语义证据，不是像素坐标真值；不得进入运行时配置或样品/候选编号规则。

## Out of Scope

- 不使用180°双拍作为初版输入前提，但不删除已有双拍试验接口。
- 不输出或写入PLC命令，不修改上位机/HMI。
- 不把单张145的0.013368°误差宣称为数据集准确率或生产精度。
- 不对未经人工确认的代表图调门限，不用固定31°/328°屏蔽候选。
