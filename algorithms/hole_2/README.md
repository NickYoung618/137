## 现拍姿态注册适配

`current_capture.py` 是 v6 外部适配层，不复制检测核心。它从权威新BMP像素提取分布式
注册支撑，并从配对新JSON获取Phi/D7测量语义。现拍工位方向固定，直接注册估计平移、尺度与
小角度；通过原支持数、覆盖、残差、尺度和角度门后才交给 v6 `extract_image`。

运行时检测入口 `tools/run_current_capture.py` 没有目标 LabelMe 参数，只接受权威参考JSON/BMP、
目标图、版本化配置和输出路径。目标真值只能在检测结果写出后由`tools/evaluate_current_capture.py`
离线读取。图片、私有标注、JSONL与运行输出均不得进入Git。
