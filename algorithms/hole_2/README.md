`current_capture.py` 是 v6 外部适配层，不复制检测核心。它使用上述旧参考标注中的圆/圆弧

不变。

版本化配置和输出路径。负责人确认的现拍 JSON 只能在检测结果写出后由
`tools/evaluate_current_capture.py` 离线读取。图片、私有标注、JSONL 与运行输出均不得进入 Git。
